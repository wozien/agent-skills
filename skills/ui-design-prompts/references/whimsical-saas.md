# Whimsical SaaS

- **id:** `whimsical-saas`
- **别名:** 俏皮 SaaS, Indie SaaS, 手作感, 独立黑客落地页
- **一句话:** 手作能量、独立灵魂，却意外能转化。
- **适用:**
  - 独立创始人与独立黑客 SaaS 产品
  - 面向开发者或创作者受众的消费应用
  - 有个性的一次性付费产品
  - 创始人即品牌的产品
  - 任何想从无菌 VC 风 SaaS 里跳出来的产品
- **避免:**
  - 需要信任信号多于个性的企业级 B2B 产品
  - 必须严肃的医疗、法律或金融产品
  - 面向 Fortune 500 买家的产品
  - 任何需要看起来「企业」的东西
- **来源:** https://uidesignprompts.com/prompts/whimsical-saas

## Prompt

## 俏皮 SaaS 设计系统

### 气质
手作、玩味、直截了当。感觉像一个人深切在意每个像素做出来的。个性大声、自信 — 但底层结构干净、以转化为中心。想象: 真正会设计的独立黑客。每个区块都让你略微惊喜，却又完全有意图。

### 色彩系统
- 页面背景: #FDF9E3 — 暖奶油色，绝不用纯白。单单这一色定下整页温暖手作调。
- 品牌橙: #F0603A — hero 展示文字、CTA 按钮、定价卡头、强调元素
- 强调黄: #F5D800 — 深色面板上的数据、XP/分数值、页脚列标题、勾选图标填充
- 深色 / 文字: #1A1A1A — 正文、区块标题、按钮边框/阴影、深色面板
- 深色面板: #1C1C1C 或 #212121 — 功能展示卡、隐私/数据区、页脚
- 白色: #FFFFFF — 定价卡主体、橙底按钮文字、深色面板上的文字
- 弱化: #555555 或 #666666 — 奶油背景上的正文
- 绝不用: 企业蓝、灰色当主色、整页区块用纯黑背景

### 字体 — 最重要的规则
三种字体角色，绝不混用:

**1. 展示 / Hero 标题**
- 字体: Fredoka One、Boogaloo，或任何气泡圆角展示字体
- 始终大写
- 颜色: #F0603A（橙）
- 描边效果: 厚深色描边，模拟漫画字
  ```css
  -webkit-text-stroke: 3px #1a1a1a;
  text-shadow: 3px 3px 0 #1a1a1a, -1px -1px 0 #1a1a1a, 1px -1px 0 #1a1a1a, -1px 1px 0 #1a1a1a;
  ```
- 尺寸: hero 用 clamp(48px, 8vw, 96px)。较小区块标题: clamp(28px, 4vw, 48px)
- 行高: 0.95–1.05 — 非常紧
- 用于: hero 标题、主区块标题、定价区标题

**2. 区块小标题**
- 字体: Fredoka One 或加粗圆角无衬线，**无**描边
- 小写或标题大小写（**不是**全大写）
- 颜色: #1A1A1A
- 尺寸: clamp(20px, 3vw, 32px)，字重 700
- 用于: 功能小标题（「Get Your Posture Score」）、卡片标题

**3. 正文 / 其余一切**
- 字体: 'Courier Prime'、'Courier New'，或任意等宽
- 颜色: 奶油底上 #555555，深色面板上 rgba(255,255,255,0.75)
- 尺寸: 14–16px，line-height 1.7
- 用于: **所有**正文、功能要点列表、定价功能列表、导航链接、页脚链接、法律文字、副标题
- 这不可妥协: 正文用等宽是本系统最鲜明的排印选择

**深色面板上:**
- 标题: 白色，Fredoka，大写，**无**描边（描边在深色上读不清）
- 数据/数字: #F5D800 黄，Fredoka，加粗
- 正文: 等宽，rgba(255,255,255,0.75)

### 导航栏
- 背景: 透明（坐在奶油底上）
- Logo: 圆角方形图标（插画吉祥物或 emoji 风）+ 品牌名用正文字体或浅无衬线
- 右侧: ghost 胶囊按钮（「Pricing」）+ 橙色胶囊 CTA（「Buy now」）
- Ghost 按钮: 2px solid #1A1A1A 边框，奶油/白背景，border-radius 100px，等宽字体
- CTA 按钮: #F0603A 背景，白字，border-radius 100px，2px solid #1A1A1A 边框，box-shadow: 3px 3px 0 #1A1A1A
- 链接无下划线、无悬停背景 — 只有颜色过渡

### Hero 区
- 背景: #FDF9E3（奶油）
- 展示标题: 巨大、橙色、描边、大写、Fredoka — 约占视口高度 40-50%
- 副标题: 等宽，居中，16-18px，深色，max-width 560px
  - 副标题中的关键词用红/橙虚线框高亮: `border: 1.5px dashed #F0603A; padding: 2px 6px; border-radius: 4px`
  - 关键词加粗用 `font-weight: 700`
- 主 CTA: 大胶囊按钮，#F0603A，白字，2px 深色边框，4px 深色右下阴影，border-radius 100px，padding 14px 36px，font-size 18px，Fredoka 或加粗圆角字体
- CTA 下方: 小等宽文字 「30-day money-back guarantee」或信任文案，弱化色
- 装饰吉祥物/emoji 散落在边距，低透明度（8-15%）

### 区块标签胶囊
- 用于在内容上方标注特殊区块（「PRIVACY FIRST」「ONE-TIME PAYMENT」）
- 样式: 深色背景 (#1A1A1A)，白等宽文字，border-radius 100px，padding 6px 18px，font-size 12px，font-weight 500，letter-spacing 0.05em
- 居中于区块内容上方，略重叠区块边框
- 备选: 奶油底区块用奶油背景 + 深色边框

### 功能区
- 布局: 交替两列 — 左文 + 右深色 UI 卡，然后左深色 UI 卡 + 右文
- 文字列: 小标题（加粗圆角，无描边）+ 正文段（等宽）+ 清单项
- 深色 UI 卡: #1C1C1C 背景，border-radius 12-16px，overflow hidden — 展示应用截图或模拟 UI
- 列间距: 48-64px
- 区块间距: 主区块之间 80-100px

### 清单项
- 图标: 黄圆 (#F5D800)，24px，border 2px solid #1A1A1A，内含深色 ✓ 勾
- 文字: 等宽，14-15px，奶油底上 #1A1A1A
- 图标与文字间距: 12px
- 项间距: 12-16px

### 深色面板区
- 通宽深色卡: 背景 #1C1C1C，border-radius 20-24px，padding 48-64px
- 区块标签胶囊坐在上方，略重叠顶边
- 内容: 居中图标（彩色圆，56-64px）+ 大白展示标题（Fredoka，大写，**无**描边）+ 等宽正文
- 数据行: 3 列，数值用黄 Fredoka 字体（大，36-48px 加粗），下方标签白等宽
- 用于: 隐私/信任区、数据 callout、任何「严肃但仍合品牌」的内容

### 定价卡
- 独立居中卡片 — **不是**方案网格（俏皮 SaaS 常常只有一个价格）
- 卡片: 白背景，border-radius 16-20px，border 2px solid #1A1A1A，box-shadow: 6px 6px 0 #1A1A1A
- 轻微逆时针旋转: transform: rotate(-1deg) 或 rotate(-0.5deg) — 给出手作感
- 卡头条: #F0603A 橙，padding 12px 20px，等宽文字 「ONE-TIME PAYMENT」白色，右侧小圆点 radio
- 价格展示: 巨大手写/圆角字体，深色 — 现价大，旧价小 + 灰色删除线 + 位于主价格左/上方
- 功能列表: 黄色清单项（同上）
- CTA 按钮: 全宽、橙、胶囊形、深色边框 + 阴影、白字、Fredoka 字体

### 定价标题（卡片上方）
- 定价区标题用展示字体（Fredoka，描边，大写，橙）
- 要挑衅且具体: 直接比价值（「CHEAPER THAN ONE DOCTOR VISIT」）
- 副文等宽、居中、用具体数字支撑比较

### 深色 UI 卡（功能模型）
- 背景: #1C1C1C 或 #212121
- Border-radius: 12-16px
- 内含看起来真实的迷你 UI: 表格、排行榜、应用截图
- 内部标题: 黄 (#F5D800) Fredoka，大写
- 内部文字: 白等宽
- 直播指示: 绿点 + 小等宽 「LIVE」文字

### 信件 / 叙事区
- 上方深色胶囊标签: 「A letter from the future」 — 深色背景，白圆角字体
- 视觉: 插画信封，信纸探出 + 蜡封
- 信纸: 米白/陈年纸质感 (#F0EDE0)，打字机字体 (Courier)，文字深棕
- 情感强调用红/橙加粗
- 这一区纯叙事 — 无按钮、无要点，只有故事

### 页脚
- 背景: #1C1C1C（与面板相同深色）
- 顶部强调: 最顶 2-3px 细橙/红渐变线
- 左: 品牌名用展示字体（Fredoka，橙+描边）+ 创始人头像（小圆照片）+ 「Built by [Name]」等宽 + 1-2 句个人起源故事等宽，rgba(255,255,255,0.6)
- 右: 3 列，黄大写 Fredoka 标题（「PRODUCT」「LEGAL」「SUPPORT」）+ 等宽链接 rgba(255,255,255,0.7)
- 底部: 细分隔 + 居中版权等宽 + 小吉祥物 emoji
- 无重边框或盒子 — 仅靠颜色对比分区

### 响应式规则
- 移动: 展示标题缩到 clamp(36px, 10vw, 56px)
- 功能区: 单列堆叠，深色 UI 卡在文字下方
- 深色面板: padding 减至 32px 20px
- 定价卡: 移动端去掉旋转，全宽
- 导航: 汉堡菜单，隐藏 ghost 按钮，保留 CTA

### 散落装饰元素
- 小吉祥物/logo 图标散落在页边，透明度 8-12%
- 克制使用: 每个页面区块最多 2-3 个
- 位置: absolute，在主内容流之外，不可交互
- 尺寸: 20-40px
- 这增加「手作个人项目」质感，又不挤占内容

### 不要这样做
- 不要把展示字体（Fredoka+描边）用于正文 — 正文**只用**等宽
- 不要在深色背景上用描边效果 — 读不清
- 不要把所有文字居中 — 功能文案左对齐，仅 hero 与深色面板区居中
- 不要用渐变 — 本系统是扁平的（阴影靠偏移 box-shadow，不是模糊）
- 不要超过一个定价方案 — 俏皮 SaaS 很直接: 一个产品，一个价格
- 不要把奶油背景做成纯白 — 特指定 #FDF9E3
- 不要用图标包里的圆角图标 — 用 emoji 或定制插画吉祥物
- 不要加超出轻微悬停抬起的动画 — 个性来自排印，不是动效
