# Sketch Design

- **id:** `sketch-design`
- **别名:** 手绘风, 素描 UI, 手绘界面, 笔记本草图风, Sketch 设计
- **一句话:** 看起来像手绘。感觉活着。
- **适用:**
  - 创意和艺术产品
  - 设计师和插画师的作品集站点
  - 教育或儿童产品
  - 温度和人性重要的工具
  - 希望从精致 SaaS 中脱颖而出的产品
- **避免:**
  - 企业或金融产品
  - 信任信号高于一切的产品
  - 需要精确的数据密集型仪表盘
  - 需要精致、高端形象的品牌
- **来源:** https://uidesignprompts.com/prompts/sketch-design

## Prompt

## 素描设计系统

### 气质
手绘、不完美、活着。感觉像有才华的设计师在笔记本里勾出了 UI。温暖、可接近、毫不含糊地人类。每个元素都故意略微不完美——线条略偏、填充略不均、边框略晃。

### 布局规则
- 松散、有机的布局——没有东西感觉被网格死锁
- 卡片和元素轻微旋转（transform: rotate(-0.5deg) 到 rotate(1deg)）
- 不均匀间距可以接受——它加强素描感
- 内容区可以装在带粗糙边缘的「纸」或「卡片」形状里
- 英雄区鼓励不对称

### 色彩系统
- 背景：米白纸质纹理 (#FAFAF5 或 #FFF9F0)
- 文字：深铅笔 (#1C1917 或 #292524)
- 主填充：用浅色水洗（黄、蓝、绿，30-50% 不透明度）
- 强调：一种用于高亮的大胆颜色（terracotta #C2410C，或深蓝 #1D4ED8）
- 避免：高饱和亮色、深色模式、纯白或纯黑

### 字体
- 使用手写或素描风格字体：Caveat、Patrick Hand、Kalam 或 Architects Daughter
- 有意混合字重——某些标题可以感觉像随手写的
- 轻微字距变化没问题
- 避免：极干净的几何无衬线（会打破错觉）

### 边框（核心）
- 使用基于 SVG 或 CSS 近似的粗糙边框
- border-radius 应略微不均匀，或用 clip-path 做有机形状
- 描边线应看起来手绘（宽度略有变化）
- 阴影模拟铅笔落影：box-shadow: 3px 3px 0px rgba(0,0,0,0.15)
- 避免：完美圆角、锐利几何边框

### 背景与填充
- 通过 CSS 噪点或 SVG 滤镜施加微妙纸质纹理
- 用浅色填充色块高亮区块（像荧光笔）
- 用虚线或点线边框暗示勾勒轮廓
- 水彩风格色块或形状适合作为装饰元素

### 按钮与输入
- 按钮看起来手绘：边框略不均，填充粗糙
- 使用 border: 2px solid #1C1917，圆角略有变化
- 悬停：填充偏移，轻微旋转或缩放（transform: rotate(1deg) scale(1.02)）
- 输入：看起来像纸上画的表单栏——细边框，无厚重样式

### 插画与图标
- 使用手绘图标集（Iconoir，或自定义 SVG 插画）
- 描边宽度略有变化的线性图标
- 小素描批注（「← try this!」、「★ new!」）增加个性
- 元素之间的箭头连接应看起来手绘

### 阴影
- 没有柔和模糊阴影
- 硬偏移阴影：box-shadow: 4px 4px 0px #1C1917
- 或铅笔素描阴影：box-shadow: 2px 3px 0px rgba(0,0,0,0.2)

### 动画
- 悬停时微妙晃动（关键帧 rotate: -1deg → 1deg → 0deg）
- 元素在加载时用 SVG stroke-dashoffset 动画「画入」
- 动画保持好玩但不分心

### 内容语气
- 对话式、温暖、略非正式
- 批注和页边笔记增加个性
- ✗ 「Optimize your workflow with enterprise-grade solutions」
- ✓ 「Here's how it works → (it's pretty simple)」
