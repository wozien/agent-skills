# Indie SaaS

- **id:** `indie-saas-retro-utility`
- **别名:** 独立 SaaS, 个人开发者落地页, 文档风 SaaS, 独立产品页, 反企业落地页
- **一句话:** 诚实。直接。由一个当真的人做出来。
- **适用:**
  - 独立 SaaS 产品和单人创始人工具
  - 希望感觉诚实直接的自举产品
  - 广告网络、newsletter 和垂直工具产品
  - 创始人即品牌的产品
  - 任何希望感觉像一个人做的、而不是一个团队做的东西
- **避免:**
  - 需要信任信号与正式感的企业或 B2B 产品
  - 面向非技术受众的消费级应用
  - 视觉丰富度和图像承载价值主张的产品
  - 任何需要强色彩品牌的产品
  - SKU 很多的电商或市场

## Prompt

## 独立 SaaS 设计系统

### 气质
反企业、个人、毫不留情地直接。这是一个会把东西做出来、没时间搞装饰泡沫的独立 maker 的设计语言。页面读起来像排版良好的文档，不是营销网站。每个区块都像创始人自己写的——坦率、自信、略带观点。产品把一件事做好，页面在前 10 秒就把这件事变得无法错过。

参考感受：一篇长文落地页坐在居中的文档栏里，米白页面背景、干净的 1px 区块分割、零投影、零渐变、零英雄图，偶尔用手绘黑白插画来人性化。

### 色彩系统 — 严格约束
这是近乎单色的系统。颜色只作为文字出现——不用作背景、边框或装饰元素。

- 页面背景：`#F2F2EF` — 温暖米白，不是纯白，不是灰。像略微陈旧的纸。
- 内容栏背景：`#FFFFFF` — 纯白，制造「纸页浮在桌面上」的效果
- 墨色：`#0D0D0D` — 近黑，用于标题、粗体、激活元素
- 正文：`#1A1A1A` — 与墨色同族，用于段落
- 弱化文字：`#666666` — 区块标签、次要描述、说明
- 边框：`#E0E0DC` — 唯一边框色，1px，到处用作区块和单元格分割
- 幽灵按钮背景：`#EAEAE6` — 用于次级/描边胶囊按钮
- 高亮强调（非常克制使用——每页最多一处）：`#F5A623` 或 `rgba(245,166,35,0.25)` 作为单个关键短语的文字背景高亮。像纸上的荧光笔。
- 零其他颜色。没有蓝、没有绿、没有紫、没有渐变。

### 字体 — 一种字体，两种字重
只用一种字体家族。Inter、Plus Jakarta Sans，或类似现代几何无衬线。

层级：
- 区块微标签：14px，weight 400，颜色 `#666666`，不大写，无字距。某些区块以 `#` 为前缀（例如「# For SaaS, AI Agents...」或「How It Works?」——非正式、随意）
- H1（英雄标题）：48–60px，weight 700–800，颜色 `#0D0D0D`，line-height 1.05–1.1，letter-spacing -0.02em
- H2（区块标题）：36–48px，weight 700，颜色 `#0D0D0D`，line-height 1.1，letter-spacing -0.01em
- H3（功能/卡片标题）：18–22px，weight 700，颜色 `#0D0D0D`。后面跟冒号：例如「Banner Ads:」——标题始终包含冒号作为风格选择。
- 正文章节：16–18px，weight 400，颜色 `#1A1A1A`，line-height 1.65。可以连续 2–3 段短段落。
- 正文强调/粗体短语：同尺寸但 weight 600–700 — 用于砸出一个特定词或数据
- 副文 / 弱化：14–15px，weight 400，颜色 `#666666`

**关键字体规则：** 标题不居中。一切左对齐。任何地方都没有居中的正文。这是文档，不是海报。

### 布局架构 — 文档栏
页面结构为单列居中内容：
- 页面背景：全宽 `#F2F2EF`
- 内容栏：`max-width: 860px`，`background: #FFFFFF`，用 `margin: 0 auto` 居中
- 内容栏有可见左右边框：`1px solid #E0E0DC`
- 栏内边距：桌面 `48px 52px`，移动端 `28px 20px`
- 文档栏制造在桌上读印刷页的错觉

**没有全宽彩色区块、没有彩色横幅、没有全出血图片区块。** 一切存在于白色文档栏内或其紧邻处。

导航（navbar）极简——坐在文档栏上方，没有全宽背景。Logo 在左，一两个导航链接或单个 CTA 按钮在右。

### 区块解剖
每个区块遵循相同结构：

1. **微标签**（可选）：14px 弱化文字 —「# For Publishers:」或「Key Features」或「How It Works?」——坐在标题上方
2. **标题**：大号粗体 H2，左对齐，最多 2–3 行
3. **副文**：1–2 段正文
4. **分割线**：`border-top: 1px solid #E0E0DC` 分隔区块。规则前区块之间没有额外 margin/padding——规则本身就是分隔。
5. **内容区**：功能网格、插画面板或问答列表

区块没有自己的背景色。一切是白或相对白色栏透明。1px 边框承担全部视觉分隔工作。

### 功能网格（单元格边框模式）
功能、收益和步骤的核心布局模式：

```
┌────────────────┬────────────────┬────────────────┐
│ 图标            │ 图标            │ 图标            │
│                │                │                │
│ 标题:           │ 标题:           │ 标题:           │
│ 描述            │ 描述            │ 描述            │
└────────────────┴────────────────┴────────────────┘
```

规则：
- 3 列，每个单元格用 `1px solid #E0E0DC` 垂直分割线隔开
- 整个网格包在 `border: 1px solid #E0E0DC` 中（上下也有）
- 无卡片背景、无阴影——单元格透明
- 单元格内边距：`24px 24px` 或 `28px 24px`
- 图标：28–36px SVG 线性图标，仅描边（无填充），`color: #0D0D0D`，1.5–2px 描边
- H3 标题始终以冒号结尾：「Earn Revenue:」、「Quick Sign-Up:」等
- 正文：14–15px，弱化，2–3 行短句

在 3 列功能网格下方，加一行 **2 列 CTA 行**（同样带边框，同样边框风格）：
- 左单元格（更宽）：标题文字 + CTA 按钮 —「今天就开始用 [Product] 赚钱」
- 右单元格：手绘线描插画——反映功能集的角色或插画

### 插画系统
黑白线描插画贯穿全页：
- 风格：手绘角色插画，细 1.5–2px 描边，纯黑 `#0D0D0D` 配白
- 不是扁平图标——真正在做事的插画角色（人在写、人在笔记本前等）
- 用于：功能网格下方的 2 列 CTA 行、创始人/联系区块、区块装饰
- 永不着色——始终单色
- 尺寸：小场景 120–180px，功能行 220–280px
- 放在 2 列行右单元格内右对齐

### 按钮系统
只有两种按钮变体。都是胶囊形（`border-radius: 999px`）。没有其他按钮形状。

**主按钮（黑胶囊）：**
```css
background: #0D0D0D;
color: #FFFFFF;
padding: 12px 22px;
border-radius: 999px;
font-size: 15px;
font-weight: 500;
display: inline-flex;
align-items: center;
gap: 8px;
border: none;
```
始终在左侧带小图标——描边 SVG 图标，白色，约 16px。悬停：轻微降低不透明度（0.88）或背景略微变浅到 `#1A1A1A`。

**次按钮（幽灵胶囊）：**
```css
background: #EAEAE6;
color: #1A1A1A;
padding: 12px 22px;
border-radius: 999px;
font-size: 15px;
font-weight: 500;
display: inline-flex;
align-items: center;
gap: 8px;
border: none;
```
也在左侧有小图标。悬停：背景略微加深到 `#DDDDD8`。

**永远不要用：**
- 圆角矩形按钮
- 渐变按钮
- 仅描边/仅边框按钮
- 比文字 + 内边距更宽的按钮
- 一行超过 2 个按钮

### 导航
绝对极简的导航栏。无背景色、无边框、无阴影：
- Logo：32–36px，黑色，左对齐 — 图标标记 + 字标在一行
- 右侧：单个「Get Started ▾」下拉按钮或一个胶囊 CTA 按钮
- 没有滚到区块的导航链接
- 高度：约 60–64px
- 与英雄区用一条 `1px solid #E0E0DC` 水平线分隔

### 英雄区
英雄区是简单的文档式页头——不是全屏英雄：
- 微标签行：`# For [audience category], [category], [category].` — 弱化，14px，weight 400
- H1：48–56px，粗体，左对齐，最多 2 行
- 2 段诚实正文——直接、略带观点，第一人称或产品口吻。每段 2–4 句。
- 两个胶囊按钮并排：主（黑）+ 次（幽灵）
- 没有别的。没有数据、没有社交证明、没有英雄图。只有文字 + 按钮。

英雄区与下一区块用 `1px solid #E0E0DC` 规则分隔。

### FAQ / 手风琴区块
- 区块标签：`# FAQ` + 大号 H2 标题
- 带链接的引言（例如「在 LinkedIn、Twitter 或 Email 上联系。」）
- 每条 FAQ：`border-top: 1px solid #E0E0DC`，问题在左，chevron 图标在右
- 问题文字：16–17px，weight 700
- 回答文字：15px，weight 400，弱化色 `#444444`，打开后出现在下方
- 无手风琴背景、无阴影——纯边框分隔列表
- 打开项没有不同背景——只是文字在下方展开

### 创始人 / 联系区块
个人触感——产品背后的人：
- 左：头像（圆角方形肖像，约 68px，1px 边框）+ 姓名 +「Got a question? ↗」+ 作为行内文字链接的社交链接
- 右：手绘插画（铅笔在写、灯泡等）
- 此区块由 `border-top: 1px solid #E0E0DC` 和 `border-bottom: 1px solid #E0E0DC` 包裹
- 无特殊样式——只是两个元素在一行中平衡

### 产品插画面板（广告/功能模型）
对于需要展示 UI 或广告形态的产品：
- 浏览器 chrome 模型：圆角矩形，深色顶栏（黑背景、3 个白圆），内部灰条代表内容
- 仅灰度——模型中无彩色
- 3 个模型显示在 3 列网格中，各自在带边框的单元格里
- 标签出现在每个模型下方：「Square Banner」、「Sidebar Ad」、「Full Banner」

### 响应式行为
- 桌面：860px 文档栏，可见页边露出米白背景
- 平板（768px）：栏内边距减到 `28px`，3 列网格保持 3 列但压缩
- 移动端（480px）：文档栏贴边（无页边），隐藏左右栏边框，功能网格塌成 1 列堆叠，每个单元格用水平 1px 规则代替垂直分割

### 切勿做
- 不要给区块加任何彩色背景
- 不要在任何地方用投影——卡片、按钮或文档栏都不要
- 不要居中对齐正文
- 不要在英雄区加英雄图、截图或应用 UI 截图
- 不要用渐变按钮或渐变文字
- 不要加彩色背景的页脚——页脚应朴素，同一白色栏
- 不要用超过 2 种字体
- 不要用彩色图标——所有图标都是黑色
- 不要加带彩色数字的数据条——如果展示数据，它们是行内朴素粗体文字
- 不要加带头像和星级的评价卡——此设计不用那种评论方式

### 文案语气（匹配风格的关键）
文案必须感觉像创始人写的：
- 直接，略冲：「Google、Facebook 和其他那些？完全是垃圾。」
- 第一人称或产品口吻：「所以我做了一个更好的广告网络。」
- 对权衡和竞品诚实
- 短句。有力。没有营销腔。
- 用真实数字：「Try for $5」、「100% human impressions」
- 功能标题带冒号：「Banner Ads:」、「Earn Revenue:」

视觉风格和写作风格不可分割——扁平语气，扁平设计。
