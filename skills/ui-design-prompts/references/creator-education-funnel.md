# Creator Education Funnel

- **id:** `creator-education-funnel`
- **别名:** 创作者教育漏斗, Fieldwork Studio 设计系统, 课程同期班落地页, 教练招生页
- **一句话:** 用个性去教。建立信任。让下一步清晰可见。
- **适用:**
  - 独立创作者销售一门旗舰数字课程
  - 有清晰课纲和每周交付物的直播同期班
  - 邀请合格访客预约通话的教练与导师
  - 围绕实用技能和学员作品搭建漏斗的教育者

## Prompt

## 创作者教育漏斗 — Fieldwork Studio 设计系统

### 1. 构建这段体验

用下面指定的原始 Fieldwork Studio 主题，为创作者、课程、同期班或教练产品创建完整、响应式的营销漏斗。访客应理解预期成果、看到他们实际会做出或练习什么、评估教学方式，并采取一个清晰的下一步。

交付一页完成的页面：有目的的图像、原创文案、可用导航、可展开课纲与 FAQ 行，以及可用的报名或咨询路径。使用用户现有框架和项目约定。若未提供技术栈，使用语义 HTML、CSS 和最少 JavaScript。设计必须不依赖特定组件库、框架或外部参考网站也能工作。

把本规范当作完整视觉源。更换题材时保留其色板角色、排印、居中主视觉、带框工作坊视觉、编号学习卡、更深的导师区块、间距和区块顺序。有用户提供的内容和去向时使用它们。否则使用下面连贯的虚构示例，并在页脚标明示例内容。

### 2. 原始主题与可识别细节

主题名：**Fieldwork Studio**。气质是独立学习工作室：实用、欢迎、自信、精心构图。深森林绿和编辑式排印给材料呼吸空间。赭石标记下一步行动。羊皮纸像工作手册里克制的纸质高亮。工作坊照片和可触摸的学员作品把承诺连接到真实劳动。

保留这七个视觉锚点：

1. 深森林绿画布，象牙色标题和细水平线。
2. 居中、超大、两到三行的主视觉标题，恰好有一个短短语用羊皮纸标出。
3. 主视觉文案下的宽工作坊媒体框，窄说明轨，桌面上有一张编号项目单重叠一角。
4. 编号学习卡：上方面板像印刷课程封面，下方面板含实用产品细节。
5. 赭石主按钮配小箭头图标；更安静的下划线次要链接。
6. 全宽更深的导师区块，大肖像或工作室器物旁配简洁教学陈述。
7. 编辑式证明卡，以及突出的单一产品报名面板，导向重复的最终行动。

使用强对齐、细线、真实内容和刻意留白。装饰物限制在媒体和封面艺术中。整页应像一个小型、认真的教育品牌，带有独特视觉系统。

### 3. 内容默认值与漏斗模式

每生成一页只用一种模式。用户未给出产品类型时默认 **同期班**。不要向访客展示模式切换器。

| 模式 | 处处的主行动 | 需强调的产品细节 |
| --- | --- | --- |
| 自定进度课程 | 获取课程 | 课时、访问期限、学习前置、项目、价格 |
| 直播同期班 | 加入下一期同期班 | 时长、每周投入、直播形式、反馈、下一确认开课日 |
| 教练 | 预约匹配通话 | 目标客户、教练方法、课时形式、范围、预约流程 |

虚构示例默认：
- 品牌：**Fieldwork Studio**。
- 产品：**The Creator Practice**。
- 受众：把有用知识变成可教产品的独立专家。
- 形式：六周同期班，每周一次工作坊和一次实践作业。
- 主视觉：**Turn what you know into something worth teaching.** 只把 “worth teaching” 标成羊皮纸。
- 支撑文案：“Shape your expertise into a clear offer, build the first lessons, and practice sharing them with the people you want to help.”
- 主标签：**加入下一期同期班**。次标签：**探索项目**。
- 讲师：**Alex Morgan**，标注「项目引导者」；不要编造职业资历。
- 六项交付物：受众简报、产品大纲、课时地图、示例课时、邀请页、交付计划。
- 不要编造开课日、直播可用性、学员数、评分、媒体背书、收入主张、折扣或保证。未知开课日写成「报名前提前公布日程」。
- 独立概念且未提供价格时，报名面板应写「索取项目详情」，并提供清晰标注的本地咨询表。提交按钮标为「预览咨询」；校验后说明什么也没发送。主视觉和导航上保留「加入下一期同期班」作为漏斗意图；那些链接导向此面板。
- 演示学员故事在每张卡上清晰标注 **说明性学员示例**。用描述性说明展示示例作品或预期学习里程碑，而不是伪造背书。有真实提供的证言时，使用真实引言、署名和获许可素材。

### 4. 颜色令牌与用法

使用这些精确默认值。一次性定义为 CSS 自定义属性或等价主题令牌。

```css
:root {
  --canvas: #14251F;
  --card: #1D332A;
  --text: #F5F2E8;
  --muted: #BCCBBE;
  --rule: #3E5A4B;
  --ochre: #D4A76A;
  --ochre-hover: #BE8F54;
  --parchment: #E8DCA5;
  --slate: #284337;
  --deep-stage: #0E1B16;
  --on-stage-muted: #CFD8CB;
  --content-max: 1200px;
  --radius-control: 10px;
  --radius-card: 18px;
  --radius-media: 24px;
}
```

- 画布是深森林页面背景；抬起的森林属于内容卡、表单和报名面板。
- 阅读象牙是标题、正文和图标色。次要鼠尾草绿用于支撑文字；更深导师区块使用 `on-stage-muted`。
- 赭石留给主按钮填充和课程封面细节；文字链接和小激活标签用暖沙（#E8C994）。所有填充主按钮用赭石配森林（#14251F）文字，包括更深导师区块中的按钮。
- 羊皮纸用于短主视觉标记、一块封面艺术字段和紧凑编号标记。羊皮纸上放画布色文字；远离长正文段落和象牙文字。
- 森林板岩是课纲、支撑艺术形式和选中手风琴行的安静背景。
- 大面积使用画布、抬起森林和深舞台。赭石和羊皮纸合计保持在总页面积约 15% 以下。实际摄影不受此面积规则约束。
- 抬起表面边框用 `1px solid var(--rule)`；导师区块线条用 16% 不透明度的白。
- 文字放在实色表面上。渐变仅在需要可读性时作为短图像说明遮罩被允许。

### 5. 排印与文案密度

标题和字标：**Manrope**，字重 600、700、800。正文和控件：**DM Sans**，字重 400、500、600、700。小课纲数字可用 `ui-monospace, monospace`。字体失败时用系统无衬线回退；保持同样尺寸和宽度。用项目字体机制或标准字体样式表每个家族只加载一次。

| 元素 | 桌面 | 移动 | 规则 |
| --- | --- | --- | --- |
| 主视觉 H1 | 76px / 800 / 1.05 | 40px / 800 / 1.1 | -0.045em tracking；最大宽 940px |
| 区块 H2 | 44px / 700 / 1.14 | 30px / 700 / 1.2 | -0.035em tracking；最大宽 680px |
| 产品与卡片 H3 | 24px / 700 / 1.25 | 22px / 700 / 1.3 | -0.02em tracking |
| 主视觉描述 | 19px / 400 / 1.65 | 17px / 400 / 1.65 | 最大宽 620px；弱化 |
| 主正文 | 16px / 400 / 1.7 | 16px / 400 / 1.7 | 段落每行上限约 65 字符 |
| 导航与按钮 | 14px / 600 / 1.4 | 14px / 600 / 1.4 | 句首大写 |
| 眉题 | 11px / 700 / 1.4 | 11px / 700 / 1.4 | 大写；0.12em tracking |
| 说明与元数据 | 13px / 500 / 1.5 | 13px / 500 / 1.5 | 弱化；在森林上保持可读对比 |

在这些端点之间使用流体尺寸。合适的 H1 是 `clamp(2.5rem, 5.4vw, 4.75rem)`。桌面主视觉标题保持两或三行，窄屏三或四行。不要强制桌面换行导致移动端出现孤立词。

仅居中主视觉文案、紧凑形式条和最终 CTA 文案。其他标题、卡片文字、课纲内容和长段落左对齐。标题应描述课时、成果或决策。用支持性、具体的声音和具体交付物。避免重复最高级、过多感叹号、恐惧框架和未解释缩写。

### 6. 布局、节奏与区块图

页面在 1200px 内容容器中居中，不含全宽背景带。外边距：低于 640px 为 20px，从 640px 起 32px，从 1024px 起 48px。使用 `min(1200px, calc(100% - 2 * gutter))` 或其等价。

间距刻度：4、8、12、16、24、32、48、64、96、112px。桌面区块用 96px 垂直内边距；移动区块用 56px。卡片间距 24px，标题到内容 32px，相关文字元素之间 12–16px。小区块眉题在标题上 12px。给文字一个目的，再加新面板。

默认页面保留此顺序：

```text
画布  01  粘滞导航
画布  02  居中承诺 + 主行动 + 工作坊媒体
抬起  03  紧凑项目事实条
画布  04  适合谁 + 三个实用成果
画布  05  精选项目 / 学习路径卡
板岩  06  编号课纲与交付物
深色  07  认识导师 + 教学方式
画布  08  学员作品 / 真实学员故事
抬起  09  一份有用的免费资源
画布  10  报名或预约面板
画布  11  常见问题
板岩  12  最终邀请 + 重复主行动
画布  13  页脚
```

主视觉是唯一大号居中开场。默认保持一个旗舰产品。学院可将第 05 节扩到三条路径；所有路径必须属于同一主题和教学品牌。资源和日志网格是可选学院扩展：最多三项，把日志放在 FAQ 之后、最终邀请之前。不要把它们加进默认单一产品漏斗。

### 7. 导航

- 高度：桌面 76px，移动 64px。画布背景，1px 底线；顶部粘滞，合理层叠顺序。避免玻璃模糊。
- 左：紧凑字标，24px 赭石方块内含简单森林（#14251F）打开书本线标；品牌名 18px Manrope 800。
- 中：四个锚链接，**项目**、**课纲**、**导师**、**故事**。链到真实区块 ID。
- 右：到 `#enroll` 的紧凑赭石主行动。措辞与所选漏斗模式保持一致。
- 低于 1024px，隐藏桌面链接行，显示带标签的菜单控件。展开菜单是页头下抬起的森林面板，垂直间隔链接。支持 Escape、`aria-expanded`、导航后关闭，以及焦点回到触发器。
- 低于 480px，可见品牌缩短为 “Fieldwork”，使用紧凑 CTA 如「加入同期班」，使品牌、行动和菜单在 320px 不换行。
- 键盘焦点时出现跳过链接。锚点目标使用 `scroll-margin-top: 96px` 桌面和 84px 移动。

### 8. 主视觉 — 承诺、行动、工作坊框

桌面导航下顶部内边距 80px，移动 48px。把以下放在单一居中列：

1. 小描边眉题徽章：示例用 “A practical learning studio”，或类似描述性的用户提供短语。用 6px 赭石点，不是直播状态指示。
2. 主承诺，徽章下 24px。限制约 8–14 个词。用扁平羊皮纸背景和 4px 行内内边距高亮一个两到四个词的短语。使用 `box-decoration-break: clone`，让换行后的高亮仍可读。
3. 支撑描述，标题下 20px，最多两句短句。
4. 描述下 28px 的行动行：带右箭头的赭石按钮，然后下划线「探索项目」链接到 `#program`。间距 16px；低于 480px 按钮叠在链接上。
5. 安静的 13px 形式行，行动行下 16px：示例为「六周 · 直播工作坊 · 边学边做」。只用提供的产品事实。

媒体舞台放在形式行下 48px。最大宽：1080px。抬起森林框，10px 内边距，24px 外圆角，1px 板岩线，微妙 `0 20px 56px rgba(0,0,0,0.3)` 阴影。内部图像或海报用 16:9 比例和 16px 圆角。移动端保持全宽，6px 内边距和 18px 外圆角。

使用真实工作坊、教学桌、创作者录制布置或协作学习场景，暖自然光。仅叠加左下小深森林说明板：「工作室内部」加上已知的实际提供媒体时长。为这块板在裁切中预留无字空间。桌面上在右下重叠 180px 宽抬起森林项目单 24px；给它 1px 线、12px 圆角、最多 3 度旋转。单内容：「PROJECT 01」、3 行课时地图图示，以及「从一个有用的想法开始。」保持装饰性并对辅助技术隐藏；移动端把单子作为未旋转、流入式说明放在媒体下。

仅在提供可用视频时允许居中 56px 圆形播放按钮。点击打开可访问的视频对话框；Escape 关闭，焦点回到触发器，播放停止。否则渲染静态工作坊图，无播放控件。

若无图，用森林和蓝板岩面板、打开的工作手册、赭石课时页签、羊皮纸索引卡和简单六步课时图，构建有意的扁平工作室海报。在媒体区使用 CSS 或内联 SVG。保留同样的框、裁切和说明。不要留下破图、骨架块或空灰矩形。

### 9. 项目事实与受众成果

事实条是抬起森林全宽带，上下有线，垂直内边距 24px。显示四个均匀间隔的事实，小描边图标加文字：**形式**、**时长**、**每周投入**、**你将做出什么**。桌面项用竖线分隔。移动端两列网格，低于 360px 单列。缺值时用已知产品事实替换该项，而不是猜测。这条传达产品；外部品牌 logo 仅在提供真实关系时出现。

受众区块桌面用 4/8 列分割：左含眉题、「对你已有知识的有用下一步」和一段短受众段落；右含三行堆叠成果。每行有 32px 羊皮纸数字瓷砖配画布色数字、20px 标题、短描述和细底线。示例成果：澄清一个受众、画出可教序列、做出有用的第一课。低于 768px，堆叠引言和行。描述项目帮助参与者做什么；避免承诺商业结果。

### 10. 项目卡 — 印刷封面，实用细节

标题：「从知识到实践的清晰路径。」一小段支撑段落解释产品或路径选择。

默认单一产品：一张横向精选卡，抬起森林，18px 圆角，1px 线，无默认阴影。桌面列是 42% 封面艺术和 58% 细节。移动端封面叠在细节上。封面内边距 32px；细节内边距桌面 32px、移动 24px。

封面艺术是原创印刷海报构图：森林场、左上大「01」、右上小工作室字标、赭石块后简单课时图示母题，以及羊皮纸页脚页签。保持约 4:3 宽高比，用象牙文字，羊皮纸上改用画布文字。在细节中把项目名显示为真实文字；装饰封面字母不得重复无障碍标题。

细节顺序：形式眉题、项目名、2 句成果描述、三个紧凑元数据项、三条交付物要点，以及到 `#curriculum` 的清晰「探索课纲」链接。主报名行动仍在页头、主视觉、报名面板和最终邀请。

学院变体：显示两或三张等宽竖卡，4:3 封面艺术和共享内容层级。从 1024px 起三列网格，640px 起两列，低于 640px 一列。在森林、森林板岩和羊皮纸之间变化封面场，赭石仍是操作色。用受众、形式和成果区分路径。只添加提供的路由或页内功能细节；不要编造课程页。

### 11. 课纲 — 展示作品

使用全宽蓝板岩背景。主容器内做 4/8 列分割，间距 48px。左引言含眉题「THE LEARNING PATH」、H2「小步骤。最后做出真东西。」、短解释，以及一个安静链接到 `#enroll`。右含示例同期班的六行手风琴。

每行抬起森林有 1px 线、12px 圆角、闭合高至少 80px、20px 内边距；间距 12px。页头含 36px 编号瓷砖、阶段标题、已知时的短形式元数据，以及右对齐加减图标。打开内容加两句解释、最多三条课时要点，以及标为 **你将做出** 的蓝板岩交付物条。

六周示例如下：
1. 找到有用的问题 — 受众简报。
2. 塑造产品 — 一页产品大纲。
3. 搭建课时路径 — 课纲地图。
4. 教一件有用的事 — 示例课时。
5. 邀请对的人 — 邀请页。
6. 准备交付 — 交付计划。

初始打开第一行。允许多行同时打开，用原生 `details`/`summary` 或等价可访问控件。Enter、Space 或点击切换。整个页头可交互。引言保持正常流；桌面只有站点导航粘滞。低于 1024px，引言叠在手风琴上。

自定进度模式把这些标为模块而非周。教练模式把它们变成三或四个教练阶段，用课时活动和约定交付物替换课时计数。保持同样的编号视觉处理。

### 12. 导师 — 墨色上的人味

这是最深的背景区块，节奏明显变化。垂直内边距 96px，两列布局 45% 视觉 / 55% 文字，间距 64px。768px 堆叠。

左：大 4:5 肖像或工作坊照片，20px 圆角，下方小抬起森林说明轨。选择 candid 教学或制作、自然光、不杂乱的背景。虚构示例无肖像时，使用设计过的工作室桌静物，标注「教学过程一瞥」；不要把虚构讲师身份贴到真人库存照上。

右：羊皮纸眉题、阅读象牙的「认识你的引导者」H2、姓名和提供的角色、`on-stage-muted` 的 70–100 词教学陈述，以及三条用线分隔的短原则。示例原则：解释为什么、带反馈练习、完成有用的东西。有提供时使用获许可、可核验的资历。以象牙下划线链接到 `#enroll` 结束。

在视觉旁加一个简单编号笔记本标记，最多一处装饰重叠。避免漂浮社交统计、超大引号和无关平台 logo。

### 13. 证明 — 学员作品与故事

回到画布。标题用「看看作品可以长什么样。」把一张精选证明卡跨三列网格的前两列；第三列堆两张紧凑卡。低于 1024px 用单列并保持精选卡在先。

精选卡：上方 16:10 项目预览，然后小标签、24px 标题、40–60 词描述，以及有真实署名时的紧凑署名行。其他卡用缩略图、18px 标题和 25–40 词描述。抬起森林表面，18px 圆角，24px 内边距，1px 线。无自动播放或移动证言轮播。

有真实证明时，展示提供的学员器物、情境证言，或带可用播放器的视频海报。说明学员起点、练习了什么、做出了什么。数字结果必须绑定提供的证据。

无真实证明时，用三份清晰标注的说明性作品样本：受众简报、课时地图和第一课大纲。展示实际微型文档布局，而不是通用头像和编造引言。标签 **说明性学员示例** 必须在每份样本上可见。不要显示伪造星级摘要。

### 14. 免费资源 — 一个温和入口

创建一条紧凑抬起森林带，两列资源布局：左，带赭石书脊的小森林工作手册样机；右，眉题「START WITH ONE PAGE」、H2「试试产品清晰度工作表」、一句描述，以及安静的「预览工作表」控件。资源从属于报名，所以这里用描边按钮。

若存在真实资源，打开其提供的去向或提供其文件。若无资源，打开可访问的页内预览，含五个有用提示：帮助谁、具体问题、一个实用成果、第一个练习、可管理的教学形式。不要假装下载缺失文件，或收集邮箱来揭示空内容。

若用户明确要邮箱捕获，用单个带标签邮箱字段和清晰交付行动替换预览控件。提交使用真实提供的集成；独立概念必须标明本地预览状态，且不得声称已发送邮件。

### 15. 报名 / 预约 — 一个清晰决定

给此区块 `id="enroll"`。使用抬起森林面板，24px 圆角，1px 线，桌面 40px / 移动 24px 内边距。放在画布上、主容器内。55% 描述 / 45% 决定区分割，间距 48px。桌面列间用竖线，低于 768px 堆叠时用横线。

左列：产品名、一句短成果陈述、五条简洁包含项、形式和时间投入，以及提供的支持或访问细节。仅在提供实际政策时添加退款或取消信息。

右列：已知时的价格和货币、简单支付说明、提供的开课日或下一步时机、全宽赭石行动，以及接下来会发生什么的短说明。金额用 40px Manrope 800。只用一个价格；仅当用户提供真实条款时渲染分期。教练可显示提供的课时费或「讨论是否合适」，配真实预约去向。

有真实结账或排程 URL 时，导航到那里并准确描述该去向。有咨询集成时，显示可见姓名和邮箱标签、目的、字段级错误、进行中状态，以及仅在服务器确认后的成功。若未提供去向、价格或集成，使用第 3 节定义的本地「索取项目详情」预览。把输入数据保持本地，并在提交前在表单旁说明预览状态。

不要加对比定价层、可重置倒计时、虚构席位数或折扣徽章。真实截止日期可作为安静元数据显示一次。

### 16. FAQ、最终邀请与页脚

FAQ：居中容器上限 800px，左对齐标题「几条有用细节」，六行用线分隔的手风琴，问题 18px、答案 16px。开始全关，允许多个打开答案。覆盖受众匹配、前置、每周时间、交付形式、访问/支持，以及报名或预约流程。仅在存在实际条款时添加政策问题。使用 `details`/`summary` 或带 `aria-expanded` 且正确关联面板的按钮。

最终邀请：全宽蓝板岩带，居中标题上限 680px，「为你想教的那件事腾出空间」，一句短支撑句，以及与主视觉相同的赭石主 CTA。它导向 `#enroll`；不引入新产品或转化路径。桌面垂直内边距 72px，移动 48px。

页脚：画布背景加顶线，垂直内边距 40px，左字标和一句目的，右一组紧凑的提供联系/法律链接。移动端换行。无真实去向的概念省略缺失链接，并以小页脚注显示「虚构工作室 · 示例项目内容」。不要创建假联系方式或法律页。

### 17. 组件细节

- 主按钮：最小高 52px，水平内边距 20px，圆角 10px，赭石背景，森林（#14251F）文字，14px 字重 600，16px 箭头图标配 10px 间距。页头按钮可为 44px 高。悬停用 ochre-hover，最多 `translateY(-1px)`；激活回到原位。标签在一两行内可读，不溢出。
- 次要按钮：同样几何，透明或抬起森林背景，象牙文字，1px 线。悬停用森林板岩。文字链接下划线偏移 3px；不要把整段正文当链接。
- 焦点：所有森林表面上可见 3px 羊皮纸描边，偏移 3px。永不移除键盘焦点样式。
- 徽章：紧凑最小高 28px，行内内边距 12px，全圆，1px 线，无阴影。徽章只用于形式、阶段或有意义的状态。
- 卡片：抬起森林，18px 圆角，1px 线，24–32px 内边距。默认扁平；可交互卡可抬起 2px 带微妙阴影。不要给静态信息卡加悬停效果。
- 输入：至少 48px 高，抬起森林，10px 圆角，1px 线，16px 文字，持久可见标签。错误放在相关字段旁并用 `aria-describedby` 关联；颜色是支撑信号。
- 图标：一套一致描边，20–24px，描边 1.5–2px。装饰图标对辅助技术隐藏。避免用 emoji 作界面图标。
- 封面图示：重复使用索引页签、细连接线、文档线和大阶段数字的词汇。把它们放在定义好的媒体矩形内，远离阅读文字。
- 圆角：控件 10px，小瓷砖 8px，卡片 18px，大媒体和报名面板 24px。不要把每个容器都变成药丸。

### 18. 响应式与交互规则

- 1024px 及以上：完整导航、桌面主视觉尺度、分割课纲，以及适用时的三列学院卡。
- 768px 到 1023px：紧凑导航、更小展示字号、堆叠课纲、文字仍放得下时的两列受众或报名布局。导师和报名在低于 768px 时堆叠。
- 低于 640px：单列项目卡，40px 主视觉字号，30px H2，低于 480px 全宽主视觉主按钮，堆叠媒体单说明，无装饰重叠。
- 320px：所有文字、按钮、表单、导航和手风琴控件仍在视口内。网格子项用 `min-width: 0`，弹性控件，元数据换行。
- 低于 768px 的屏幕，主视觉行动离开视图后可出现紧凑底部行动条。使用真实可见性观察器、画布背景、顶线、产品标签，以及一颗到 `#enroll` 的赭石按钮。主视觉行动、报名面板或最终 CTA 可见时，以及表单字段或对话框有焦点时隐藏它。在页面内边距中预留其高度加 `env(safe-area-inset-bottom)`。若此行为未完整实现，省略该条。
- 使用锚滚动、可访问手风琴和刻意对话框。避免滚动劫持、自动前进轮播、持久光标效果、视差和连续跑马灯。
- 过渡：控件 150–200ms；可选一次性区块揭示限制为 8px 移动、300ms。内容默认可见；脚本失败不得隐藏区块。尊重 `prefers-reduced-motion`，禁用动画滚动、变换和揭示效果。
- 对话框需要可访问标题、关闭按钮、焦点包含、Escape 处理和焦点返回。不要在用户请求的播放行动之外自动播放媒体。
- 提供语义 header、navigation、main、sections 和 footer，恰好一个 H1，顺序标题层级，以及信息图的描述性替代文本。控件至少 44px 触控目标。满足 WCAG AA 文字对比；不要在照片上用苍白标签。
- 定义图像尺寸或宽高比以防布局跳动。优先主视觉资源，推迟折页下图像。无 JavaScript 时页面内容和核心导航仍有用。

### 20. 视觉构造细节

1440px 的主视觉构图：导航占前 76px。其下，眉题、大承诺、描述和行动形成居中垂直堆。让周围森林不被打断。工作坊框从文案下开始，跨过大部分容器；其上半应进入初始桌面视口。让内容决定总主视觉高度，而不是把一切硬塞进一屏。手机上优先完整承诺和行动，再是媒体。

标题用阅读象牙；其羊皮纸短语用画布色字母。标记有方角、3px 圆角、无旋转。标题其余部分留在普通背景上。徽章透明填充和板岩边框。媒体框有可见上缘和克制黑影，感觉略抬离画布。保持照片自然着色；不要为了匹配界面而压暗面孔。

卡片解剖一致：艺术贴住内侧顶边，内容区 24px 内边距，元数据在标题上，描述间隔 12px，行动在最后内容行下 24px。网格中把卡拉到等行高并把行动行推到底。保留完整标题和自然换行。避免截断比较项目所需的信息。

课程封面艺术是微型构图，不是通用图标瓷砖。使用 32px 安全边距、56px 阶段数字、三块短连接课时块，以及一个小羊皮纸索引页签。把页签限制在一角，使其不能重叠标题。图示用 1px、40% 不透明度的鼠尾草连接线；必要标签用全对比文字。单色或图像加载失败时，真实项目标题和描述文案仍能识别产品。

所有卡在画布上用可见板岩边。可交互卡悬停时边框变为 #AC8355；键盘焦点用同样显著性而不依赖移动。每卡一个行动，避免嵌套链接。静态证明卡保留正常边框和位置。绝不要给每张卡加光晕。

按钮用紧凑圆角矩形，不是胶囊。文字和箭头对齐同一基线，作为一组居中。赭石上用深森林。禁用按钮保留可读文字并显示明确不可用状态；进行中的表单仅在真实请求期间显示小旋转加「发送中…」。状态变化时保持按钮宽度稳定。次要行动通过描边处理保持明显更安静，而不是降低文字对比。

手风琴行有森林表面、鼠尾草数字和 20px 加号图标。打开行把数字瓷砖换成羊皮纸配深色数字，并把加号旋转或换成减号。答案仍在同一卡上，用细线和 16px 顶内边距分隔。焦点环在完整 summary 行外，并保留慷慨可点区域。

表单字段在抬起报名卡内用画布填充、#779080 边框以明确控件边界、象牙输入文字和鼠尾草占位文字。焦点加羊皮纸描边；错误加带图标和 #FFB4AB 文字的行内消息。标签在字段上 8px。字段间隔 20px。为帮助消息预留空间，使校验不挤到下一控件。

资源工作手册是深色竖矩形，6px 赭石书脊、细板岩描边、小羊皮纸角页签和四条鼠尾草内容线。保持直立。定价区用大象牙数字和更小鼠尾草货币/支付标签。FAQ 行用水平分隔而不是分开的浮动卡。页脚链接用鼠尾草文字，悬停或焦点时变象牙并下划线。

森林表面上的普通文字链接和小激活标签用 #E8C994；赭石留给填充按钮和实质艺术。赭石会消失进背景处用羊皮纸焦点描边。每个高亮、边框、悬停态和弱化标签都必须对照其实际表面检查。

### 21. 完成检查

完成前，在约 1440px、1024px、768px、390px 和 320px 宽度检查渲染页。确认主视觉干净换行，媒体框和卡片封面完整，没有装饰单遮挡内容，且没有页面级横向溢出。

检查每个可见控件：移动菜单、锚点去向、课纲、FAQ、资源预览、存在时的媒体对话框，以及报名或咨询状态。从页头、主视觉和最终邀请跟随主 CTA 到同一决定面板。验证键盘焦点、Escape 行为、表单校验和减少动效行为。确认提供的线上目的地可用，本地预览交互准确描述其结果。

最终结果必须通过森林画布、大胆居中承诺、赭石行动、羊皮纸标记、带框工作坊视觉、编号学习材料、更深导师区块和清晰报名面板，可见地表达 Fieldwork Studio。保留这些具体细节，而不是用通用教育模板替换它们。
