# Cinematic UI

- **id:** `cinematic-ui`
- **别名:** 电影感UI, 电影级界面, 分镜落地页, 影院风, 镜头叙事页
- **一句话:** 一次只讲一个镜头的故事。
- **适用:**
  - 有视觉故事可讲的品牌与产品发布
  - 食品、饮品、时尚、酒店餐饮、建筑及其他影像主导项目
  - 编辑向故事、展览与娱乐发行
- **避免:**
  - 核心任务需要快速扫读或频繁重复操作
  - 现有影像无法建立一致的主体或场景
- **来源:** https://uidesignprompts.com/prompts/cinematic-ui

## Prompt

# 电影感 UI · 可复用落地页

把本设计套用到本提示所伴随请求中的品牌、产品、服务或主题。请求提供内容。本提示提供布局、视觉系统、镜头序列与交互行为。为所请求的主题撰写原创标题、标签、说明与行动文案。细节缺失时，使用中性文案，或明确标出示例数据。若涉及真实交易，请索要真实跳转地址。独立演示则链到页面上的真实区块。

## 交付物

使用项目现有技术栈。若未指定技术栈，交付一份带内联 CSS 与 JavaScript 的响应式 HTML 文件，语义化标记，原生控件。照片引用保持为 Unsplash 或其他允许既定复用与托管的开放图库的直接 HTTPS URL。用其授权源页面核验图片并署名摄影师。工作流中不要使用图片生成、下载、本地照片副本、base64 图片和随机图片接口。

## 设计系统

- 做一页四章的深色编辑向页面。画布用 #0B0D0F，细节章与图片回退用 #141618，分隔线用 #353436，主文字用 #F5EEE4，次级文字用 #BDB6AD，默认强调色与焦点环用 #E8B580。若品牌需要不同强调色，则斜体标题、小标签与主操作共用一种强调色。按钮文字颜色按对比度选择。尽可能把强调色带进摄影中可见的色调。
- 使用 Instrument Serif Regular 与 Italic，回退 Georgia；正文为 16px 系统无衬线、行高 1.55；导航、说明与章节标签为 11px 大写等宽、字距 0.14em。桌面英雄标题设为 clamp(5.5rem, 10.5vw, 10rem)，行高 0.8，字距 -0.045em。其他展示标题用 clamp(4rem, 7.5vw, 7.75rem)，行高 0.94。低于 700px 时英雄标题用 clamp(3.75rem, 16vw, 6rem)。刻意做成两行标题，第二行是短的强调色斜体。较长名称与翻译文案自然换行。
- 最大内容宽 1320px，侧边沟槽 clamp(24px, 5.5vw, 88px)，编辑区块内边距桌面约 110–150px、移动端 72–90px。用细的一像素线、直角、最小 44px 点击目标。构图交给摄影与字体。主故事中不要额外徽章、浮动 UI 和卡片网格。
- 在文案背后放定向遮罩，并在到达照片焦点主体前淡出。通过检视每张实际图片，为桌面与移动端分别设置 object-position。保留高光、焦点主体与影像质感。在渲染裁切上检查普通文字 4.5:1、大号文字 3:1。

## 四章

1. **建立世界。** 桌面用至少 100svh 的全出血开场。页头放置字标、两个短章节链接与影片操作，随页面滚动。宽度低于 700px 时仍保持字标与影片操作可见。英雄区用宽幅建立镜头，主体在右、左侧为安静阴影。在画面中部偏左沟槽处放置短眉题、两行标题、一句话，以及实心的「播放影片」操作。包含时长，以及带章节序号与下一章链接的底部分隔线。移动端把主体放在文案上方，让影像羽化进深色画布。核心主体须可辨认。
2. **展示工艺或定义性细节。** 在碳黑色上，左侧放章节序号与两行标题，右侧放约每行 30 字符的辅助段落。其下放置 3:2 的材质或主体细节，以及 4:3 的过程或使用瞬间。使用 7:5 网格、24–32px 间距，第二帧下移约 80px。两图都在细线下加说明。低于 700px 时文案与图片单列，去掉错位。
3. **给读者有用的东西。** 无图章节，三项等权，细线分隔。按主题选择有用事实、步骤、属性或品鉴笔记。用定义列表，桌面数值醒目 72–120px，标签小而低对比。有意义处用强调色单位。文字值按需缩放并允许换行。低于 700px 时纵向堆叠，用水平分隔。数字须基于所给事实，或明确标为示例配方或示意。数字价值不大时改用短词。
4. **以下一步收束。** 桌面用至少 70svh 高的另一张全出血图。主体在左，右侧放章节序号、收束标题与一个描边操作。移动端主体在上、文案左对齐。操作为与品牌相关的有效目的地。以紧凑页脚结束，承载品牌、照片署名与回到顶部链接。

把章节描述当作角色。可见区块与锚点按内容命名。以蜂蜜为例，可以是 田野 / 采收 / 品鉴笔记 / 餐桌上，配牧场或蜂巢、蜂巢结构、近距倾倒、上桌镜头。咖啡可以是 第一缕光 / 工艺 / 冲煮指南 / 这一杯，配安静的杯子、烘焙豆、冲煮镜头、完成的倾倒。工作室可用场景、材质特写、工作瞬间与完成项目。每种情况都把同一序列与构图带到新主题上。

## 按镜头角色选取源照片

1. **建立镜头** — 宽幅、侧光场景，介绍主体及其环境。文案一侧要有留白，并有纵向裁切空间。
2. **细节镜头** — 更紧的材质、成分或辨识特征。寻找定向光与可见质感。
3. **过程镜头** — 另一角度，展示主体如何被制作、使用、上桌或体验。裁切中保留手势或焦点动作。
4. **收束镜头** — 更宽或更静的画面，收束故事并为操作留出空间。用另一角度或过程之后的瞬间。

四张都要光向、色温、对比与质感一致。优先没有醒目标识或无关道具的照片。每张直接图片 URL 旁保留源页面 URL。可用时使用提供方的响应式宽度，设置尺寸或宽高比，英雄图 eager 加载，其余延后。核验直链可加载。若主机失败，深色画布、文案、链接与控件仍须可用。有意义的照片提供描述性替代文本。无法核验的照片，在画布上留空该槽位并描述需要怎样的图。

## 影片与动效

- 可选无声影片按页面顺序使用同一组四张静帧。从任一「播放影片」触发器打开原生模态对话框。每镜四秒，短交叉淡化，最多 4% 的推进。字幕写所请求品牌的故事。包含播放/暂停或重播、上一张与下一张、已过时间与总时长、带标签的进度滑块，以及关闭。
- 允许动效时打开即播放，再次打开时重置，结束时停止，文档隐藏时暂停。用按钮、Escape 或背景关闭，并把焦点交回触发器。保留焦点指示，支持触控与键盘。减少动效时打开为暂停，去掉推进、交叉淡化、平滑滚动与影像漂移。
- 保持原生滚动与普通锚点。可选漂移只作用于英雄照片，不超过 32px，按需使用 requestAnimationFrame。JavaScript 运行前内容仍可见。若影片无法初始化，在英雄区主操作位置显示下一章链接。包含跳过链接。

## 核验

在 1440 × 900 与 1200 × 750 检查完整开场构图、标题、主操作与章节链接。在 390 × 844 与 320px 宽检查裁切、换行、对比、堆叠区块与控件。核验两个影片触发器、播放、暂停、寻址、重播、Escape、焦点返回与减少动效。核验所有照片来源与操作目的地。当品牌、标题、事实与照片更换时，设计仍应可辨认。
