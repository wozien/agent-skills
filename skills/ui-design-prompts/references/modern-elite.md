## Prompt

## 现代精英设计系统（Linear / Stripe / Vercel 风格）

### 气质
极度打磨。深色模式优先。每个像素都像有意为之，每段动画都像被工程过。传达：「这是昂贵、高质量的软件。」

### 布局规则
- 使用 Bento 式网格（模块化卡片：1x1、2x1、1x2、2x2）
- 组合小卡片与大卡片以建立视觉层级
- 处处完美对齐与慷慨留白

### 色彩系统
- 背景：#0A0A0A 或 #111111
- 表面：#1A1A1A 或 #161616
- 文字：主色柔白（#E5E5E5），次级 #999
- 强调：克制的蓝（#3B82F6）、紫（#8B5CF6）、青（#06B6D4）
- 不要刺眼霓虹。不要扁平素颜色板。

### 深度与光（签名手法）
- 用径向渐变模拟光源
- background: radial-gradient(ellipse at 50% 0%, rgba(59,130,246,0.15) 0%, transparent 70%)
- 按钮光晕：box-shadow: 0 0 20px rgba(59,130,246,0.4)
- 卡片边缘：border 1px solid rgba(255,255,255,0.08)
- 应感觉光在与 UI 发生交互

### 边框（玻璃效果）
- 1px solid rgba(255,255,255,0.08)
- 悬停：rgba(255,255,255,0.15)
- 感觉像磨砂玻璃 — 不要厚重描边

### 阴影
- 非常柔、带色光晕的扩散
- box-shadow: 0 4px 40px rgba(0,0,0,0.4), 0 0 0 1px rgba(255,255,255,0.05)

### 字体
- Geist、Inter 或 Poppins
- 慷慨行高（1.7）
- 标题：#FFFFFF 或 #F5F5F5
- 正文：#A3A3A3 或 #888888

### 动画与微交互
- 悬停：边框过渡到 rgba(255,255,255,0.15)，光晕出现
- 卡片：抬升 translateY(-2px) + 阴影加强
- 过渡：150–200ms ease-out
- 避免：弹跳动效、装饰性动画

### 间距
- 慷慨且一致（8px 的倍数）
- 处处完美对齐
