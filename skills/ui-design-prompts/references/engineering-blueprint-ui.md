# Engineering Blueprint UI

- **id:** `engineering-blueprint-ui`
- **别名:** 工程蓝图 UI, 蓝图风, 图纸风界面, 技术规格 UI, 制图板界面
- **一句话:** 精确。技术。按规格绘制。
- **适用:**
  - UI kit 文档和设计系统展示
  - 开发者工具和技术产品落地页
  - 面向工程师和构建者的 SaaS 产品
  - 面向技术受众的内部工具和管理界面
  - 需要传达精度与工艺的产品
  - 设计师和工程师的作品集站点
  - 线框和原型工具
- **避免:**
  - 面向非技术受众的消费级应用
  - 需要温度、亲和或情绪柔软的产品
  - 电商或生活方式品牌
  - 健康、医疗或面向家庭的产品
  - 任何可读性必须先于风格的场景

## Prompt

## 工程蓝图设计系统

### 核心方向

创造感觉像在技术绘图板上起草的界面——精确、带标注、按规格建造。每个元素都应唤起机械示意图、建筑蓝图和 UI 组件文档页的审美。

界面应感觉：
- 技术上精确
- 有意标注
- 用手起草但用仪器测量
- 权威但不企业
- 陈旧且档案化——像牛皮纸或亚麻绘图纸

避免现代扁平设计、纯数字极简，或任何看起来来自通用 SaaS 模板的东西。

想：
- 建筑技术图纸
- 机械零件文档
- UI kit 规格页
- 工程示意图和接线框图
- 制图员标注系统

UI 应感觉像随精密硬件一起出货的文档。

### 视觉气质

每个元素应呈现为：
- 用细技术笔绘制
- 被测量并标注
- 放在网格线或点阵背景上
- 用规格标注标签
- 引用一致的尺寸系统

元素永远不应感觉：
- 玻璃感或光泽
- 霓虹或花哨彩色
- 超出规格的柔软或圆润
- 没有结构锚定地自由漂浮
- 无功能的装饰

这是技术工艺——不是装饰艺术。

### 布局规则

布局应读起来像规格文档。

规则：
- 网格线始终可见——虚线或点线，永不用实线
- 区块用精确水平线加区块标签分隔
- 尺寸标注标记出现在区块边缘（4px、8px、32px 标注）
- 内容左对齐，列结构清晰
- 稀疏用色——只有墨、纸，以及一种强调（红或蓝）
- 角落套准标记（十字准星或括号）出现在关键区块

偏好：
- 多列规格布局
- 组件展示网格
- 带标注的线框区块
- 技术标注气泡
- 页边尺/测量标签

避免：
- 带大图的居中英雄构图
- 大胆渐变背景
- 营销式情绪文案区块
- 厚重卡片阴影或柔和模糊效果
- 全宽彩色区块

### 表面与材料行为

所有表面应感觉像陈旧的技术纸。

背景：
- 主色：暖奶油或牛皮纸 (#F5F0E8, #FAF7F0, #F2EDE0)
- 网格：非常浅的暖灰线 (#D6CFC0) — 虚线或 1px
- 卡片/面板背景：略浅或纯白，带墨色边框

边框：
- 所有边框用细墨描边：1px 或 1.5px solid dark
- 虚线边框 (#D6CFC0, dash 4px gap 4px) 表示测量区
- 用 CSS 或伪元素做角落括号点缀

抬升：
- 没有柔和阴影——改用偏移阴影（2px 2px 0 #1C1917）
- 表面扁平如纸
- 「抬起」元素用紧的偏移 box-shadow，不是模糊
- 「内陷」元素用内边框或背景色偏移

### 色彩系统

色板被有意约束，感觉像纸上的技术墨。

背景色调：
- #F5F0E8 — 主牛皮纸
- #FAF7F0 — 更浅的纸白
- #FFFFFF — 纯白，用于组件内部

墨色：
- #1C1917 — 主起草墨（所有文字、边框、标注）
- #57534E — 次级标注文字
- #A8A29E — 三级/弱化标签

强调色（克制使用——每个设计一种）：
- 尺寸红：#C2410C — 用于标注箭头、高亮规格、错误状态
- 蓝图蓝：#1E40AF — 备选强调，用于标注标记、激活状态

高亮：
- #FEF08A — 关键内容上的黄色荧光笔效果
- #DBEAFE — 选中/激活组件状态的浅蓝水洗

永远不要用：
- 渐变
- 饱和或霓虹色
- 同时使用多种强调色
- 纯黑 (#000000) — 始终用起草墨 (#1C1917)

### 字体系统

字体分成两种截然不同的角色。

标注 / 标签字体（用于区块标题、标注、尺寸标签）：
- 字体：'Caveat'、'Patrick Hand'，或类似手绘风格
- 或：全大写等宽，用于更正式的技术感
- 尺寸：标注 11–14px，区块标题 20–32px
- 字重：600–700
- 字距：标签 0.05em–0.1em

正文 / 规格字体：
- 字体：'DM Sans'、'Inter' 或 'IBM Plex Sans'
- 尺寸：13–15px
- 字重：400–500
- 颜色：#1C1917（墨）或 #57534E（弱化）

标题处理：
- 区块标题全大写、宽字距
- 用单条墨线加下划线
- 永远不要用渐变或装饰性标题处理

示例：
- 区块标签：FOUNDATIONS — 13px，全大写，letter-spacing 0.12em
- 组件标签：「Primary (Default)」— 12px，居中在组件下方
- 尺寸标注：强调红的「4px ←——→ 32px」

### 标注系统（最重要的视觉特征）

蓝图 UI 的定义特征是其标注层。

尺寸标记：
- 细水平线，箭头向内指（↔）
- 测量值在线上方，小号标注字体
- 强调标注用红 (#C2410C)
- 结构标注用灰 (#A8A29E)

区块套准标记：
- 区块边界的角落括号（⌐ ¬ L ⌐）
- 区块页边的虚线测量条
- 角落小交叉线图案作为视觉锚点

标注气泡：
- 带 1px 墨边框的圆角矩形
- 小箭头或指引线指向元素
- 内部文字用标注字体
- 背景：白或黄 (#FEF08A)

区块标题：
- 全大写标签
- 左对齐
- 后跟全宽墨线（1px solid）
- 左侧小括号或箭头装饰

### 组件文档模式

每个组件或 UI 元素应以规格格式展示：

1. 组件默认状态（居中，带墨边框）
2. 下方小号标注字体标签
3. 状态变体并排展示
4. 连接相关元素的尺寸标注

始终要文档化的组件状态：
- Default
- Hover / Active / Pressed
- Disabled
- Loading / Error

### 交互与悬停状态

按钮和交互元素：
- 默认：扁平，墨边框加偏移阴影（2px 2px 0 #1C1917）
- 悬停：轻微对角位移（transform: translate(-1px, -1px)）配合更大偏移阴影
- 激活/按下：内陷外观 — 用阴影线填充或背景色偏移
- 禁用：降低不透明度（0.4），虚线边框代替实线

过渡：
- 100–150ms
- Ease-in-out
- 微妙 — 界面应感觉像纸，不是 web 应用

### 边框与几何

圆角最小且有目的：
- 默认元素：2px–4px（近方形）
- 胶囊 / 徽章：全圆（999px）但带墨边框
- 卡片：4px–6px，带可见偏移阴影
- 输入框：2px–3px，焦点时内陷外观

永远不要用：
- 大圆角（>8px），除非表示徽章/胶囊
- 无边框元素（每个组件必须有可见墨边框）
- 不可见/幽灵边框

### 网格与结构

背景网格是审美的核心部分：

点阵网格：
- background-image: radial-gradient(circle, #C5BFB0 1px, transparent 1px)
- background-size: 20px 20px

线网格（备选）：
- 24px 或 32px 间隔的虚线水平线
- 颜色：#D6CFC0
- 图案：dashed 4px / gap 4px

页边尺：
- 固定间隔的细垂直或水平尺标
- 页边用标注字体的数字或刻度
- 可选小阴影线标记网格单位

### 图标与视觉元素

使用：
- 细轮廓图标（1.5px–2px 描边）
- 感觉像制图笔画出的简单几何线性图标
- 无填充图标 — 始终轮廓
- 带墨边框的圆形或方形容器用于图标徽章

避免：
- 填充/实心图标风格
- emoji 或彩色图标
- 任何感觉像现代扁平或 Material Design 的图标风格

克制使用的技术装饰：
- 角落套准十字准星 (+)
- 元素之间的测量箭头（←→）
- 标注用虚线指引线
- 角落括号点缀（┌ ┐ └ ┘）
- 禁用/按下状态的阴影线填充图案

### 内容语气

写作应感觉：
- 技术且精确
- 规格文档语言
- 干但不冷
- 被标签和分类

使用：
- 短技术标签（「Primary (Default)」、「Level 2 (Medium Shadow)」）
- 规格语言（「Stroke Weight: 2px」、「Radius Scale: 8px」）
- 编号和分类区块
- 关键规格用标注式强调

避免：
- 营销语言
- 情绪或说服性文案
- 随意对话语气
- 修辞问句
