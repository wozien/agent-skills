# DTC Brand UI

- **id:** `dtc-brand-ui`
- **别名:** DTC 品牌站 UI, 直销品牌界面, 单品品牌体验, 消费品牌落地页
- **一句话:** 一个主视觉。一件产品。全部信念。
- **适用:**
  - 只有 1–3 个主打实体产品的品牌
  - 视觉识别强的高端消费品
  - 想摆脱通用主题的 Shopify DTC 品牌
  - 推出单一旗舰产品的创始人
  - 生活方式与身份认同和规格同等重要的产品
  - 靠设计和信念竞争、而不是靠价格的品牌
- **避免:**
  - SKU 或品类很多的大目录
  - B2B 或企业级产品公司
  - 服务业务或 SaaS 产品
  - 只靠价格竞争的大宗商品
  - 市场平台或聚合商
- **来源:** https://uidesignprompts.com/prompts/dtc-brand-ui

## Prompt

## DTC 品牌 UI 设计系统

### 核心方向
为拥有 1 到 3 个焦点产品的实体公司设计直销品牌站点。这不是目录，也不是市场。它是一次碰巧在卖东西的品牌体验。

页面只有一件工作：让访客在看到价格之前先感受到产品。

流程是顺序的、情感上有意安排的：
1. 主视觉 A — 品牌宣言。尚未展示产品。纯粹信念。
2. 主视觉 B — 产品进入画面。仍是情感的，不是理性的。
3. 产品卡 — 用户第一次能真正购买。干净、自信。
4. 生活方式网格 — 4 张真人使用产品的图。
5. Reels 行 — 一行 4 张视频评价卡。
6. 支撑区块 — 规格、保障、页脚。

### 视觉个性

模式 1 — 品牌（情感、编辑、电影感）：
- 满幅图像或视频
- 大号、自信的字体
- 文案极少 — 每个词都要挣得位置
- 充裕留白作为奢侈信号
- 深色区块与明亮产品特写形成对比

模式 2 — 转化（清晰、功能、可信）：
- 产品清晰展示在干净背景上
- 价格无需寻找即可看见
- 变体选择（颜色/尺码）明显且可触摸
- 加入购物车按钮不可能被错过
- 社会证明紧凑且具体

这两种模式在页面中有节奏地交替。访客在想要和购买之间移动。

### 色彩系统 — 品牌可替换，结构固定

```
品牌黑：          #0A0A0A  — 标题、深色区块、主按钮
灰白：            #F8F6F2  — 页面背景（暖，不是临床白）
纯白：            #FFFFFF  — 产品卡、高对比时刻
深色区块：        #111111  — 主视觉 B 背景、reels 区块
中灰：            #6B6B6B  — 次要文字、说明、元数据
边框/分隔：       #E5E5E5  — 边框、输入描边、缩略图框
品牌强调色：      [由品牌定义 — 仅一种颜色]
```

品牌强调色示例：
- Ridge: `#E8C547`（金）
- Ugmonk: `#4A7C59`（森林绿）
- Peel: `#2563EB`（电蓝）

规则：
- 绝不用强调色做大面积背景 — 只用于按钮、标签、高亮
- 强调色 CTA 按钮是页面上最重要的彩色元素
- 深色区块只用白字；浅色区块用近黑
- 同一区块内绝不要混用暖灰和冷灰

### 字体排印 — 冲击优先

展示 / 主视觉：Inter 字重 800–900、Neue Haas Grotesk，或品牌专属展示字体
正文 / UI：Inter 字重 400–600 或 DM Sans

```
主视觉 A 标题：    80–120px / 字重 900 / line-height 0.92 / tracking -0.04em
主视觉 B 标题：    56–72px  / 字重 800 / line-height 1.0
产品名：           32–40px  / 字重 700 / 颜色品牌黑
区块陈述：         48–64px  / 字重 800
正文 / 描述：      15–17px  / 字重 400–500 / 颜色中灰 / leading 1.65
价格：             28–34px  / 字重 700 / 颜色品牌黑
按钮文字：         15–16px  / 字重 700 / letter-spacing 0.02em
变体标签：         11–12px  / 字重 700 / 大写 / letter-spacing 0.08em
元数据：           12–13px  / 字重 500 / 颜色中灰
```

### 第 1 节 — 主视觉 A（品牌宣言）

全视口深色区块。只做品牌定位 — 无产品、无价格、无 CTA。

```
布局选项：
A) 文字主导 — 大标题在 #111 背景上居中或左对齐
B) 对分 — 左半深色（标题）+ 右半极端产品细节特写

内容：2–4 个词的标题，可选 8–12 个词的副行
示例："Built to last." / "Carry less. Do more." / "Engineered for every day."

主视觉 A 下方（同一深色背景）：信任条
格式：★ 4.9 评分 · 12,000+ 顾客 · $75 以上免运 · 终身保障
样式：12px，点分隔，深色上白字，居中
```

### 第 2 节 — 主视觉 B（产品登场）

产品第一次出现。仍是情感框架，不是目录框架。

```
- 产品摄影占区块宽度的 50–65%
- 背景：灰白（#F8F6F2），让产品对比最大
- 文字：产品名（大）、一行描述、CTA 按钮
- CTA：强调色的「立即选购 →」或「入手你的 →」
- 次要：「查看规格 ↓」作为幽灵文字链接
```

### 第 3 节 — 产品卡（购买时刻）

两列布局。购买发生在这里。

```
左列（50–55%）：产品图像
- 主图：大、干净、中性背景
- 下方缩略图：72×72px 方块，间距 8px，激活态 2px 边框

右列（45–50%）：
1. 品类标签        — 极小大写（EVERYDAY CARRY）
2. 产品名          — 32–40px，粗体
3. 短描述          — 1 句，中灰
4. 价格            — 28–34px，粗体，始终突出
5. 评价摘要        — ★★★★★ 4.9 · 2,847 条评价（可点）
6. 变体选择器      — 色板或尺码药丸
7. 数量控制        — +/- 极简控件
8. 加入购物车      — 全宽，高 54px，强调色背景，白字
9. 信任图标行      — 免运 · 30 天退货 · 终身保障
```

### 色板
```css
.swatch { width: 36px; height: 36px; border-radius: 50%; border: 2.5px solid transparent; cursor: pointer; }
.swatch.active { outline: 2.5px solid #0A0A0A; outline-offset: 3px; }
.swatch:hover { outline: 2.5px solid #E5E5E5; outline-offset: 3px; }
```

### 加入购物车按钮
```css
.add-to-cart {
  width: 100%; height: 54px;
  background: [ACCENT]; color: white;
  font-size: 16px; font-weight: 700; letter-spacing: 0.02em;
  border: none; border-radius: 6px; cursor: pointer;
  transition: opacity 0.15s, transform 0.12s;
}
.add-to-cart:hover { opacity: 0.88; transform: translateY(-1px); }
.add-to-cart:active { transform: translateY(0); }
```

### 第 4 节 — 生活方式网格（4 张图）

四张等宽竖图（3/4 比例）无缝一行。无文字叠层、无说明、无悬停效果。

```
每张图的情境：
1. 城市 / 通勤
2. 工作桌 / 专业
3. 旅行 / 户外
4. 特写 / 生活方式细节

网格上方：区块陈述 — 「融入每一天。」 — 48–56px，品牌黑，左对齐
间距：2px 或无
移动端：2 列 2 行网格
```

### 第 5 节 — Reels 行（社会证明视频）

深色区块（#111）。一行四张 9:16 UGC 视频卡。

```css
/* 卡片 */
.reel-card { aspect-ratio: 9/16; border-radius: 14px; overflow: hidden; background: #1A1A1A; position: relative; }

/* 播放按钮 */
.play-btn { width: 52px; height: 52px; border-radius: 50%; background: rgba(255,255,255,0.18); backdrop-filter: blur(4px); border: 2px solid rgba(255,255,255,0.4); }
.play-triangle { border-left: 18px solid white; border-top: 11px solid transparent; border-bottom: 11px solid transparent; margin-left: 4px; }

/* 叠层 */
.reel-overlay { position: absolute; bottom: 0; left: 0; right: 0; padding: 16px 14px; background: linear-gradient(transparent, rgba(0,0,0,0.75)); }
```

移动端：横向滚动（`overflow-x: auto`）。卡片不要堆叠 — 保持成行。

### 第 6 节 — 保障条

全宽深色或强调色条。三列信任，每列图标 + 粗标题 + 一行正文。

示例：
- 🛡 终身保障 — 我们把东西做得经久耐用。坏了，我们换。
- 📦 免运 — 满 $75 全免。无需优惠码。
- ↩ 30 天退货 — 不满意？退回即可，不问原因。

### 导航

```
左：品牌字标（粗、大写、紧字距）
中：3–4 个链接（产品 · 故事 · 评价 · 支持）
右：带徽章的购物车图标 + 强调色「选购」CTA

行为：主视觉 A 上透明 → 滚动后实心底加边框
高度：60–64px
移动端：汉堡菜单 + 始终可见的购物车
```

### 间距系统
```
主要区块之间：     80–120px 垂直内边距
产品卡内部：       24–32px 内边距
色板之间：         8px 间距
缩略图之间：       8px 间距
生活方式网格间距： 2px 或零
Reel 卡片间距：    16px
导航高度：         60px
```

### 不要做
- ✗ 绝不要在主视觉 A 展示产品 — 把揭示留给主视觉 B
- ✗ 按钮或 CTA 上绝不要用超过一种强调色
- ✗ 绝不要给主视觉 A 加多个 CTA — 它是品牌宣言，不是转化时刻
- ✗ 绝不要用可以套在任何品牌上的库存生活方式摄影
- ✗ 主产品图绝不要用轮播或滑块
- ✗ 绝不要藏价格 — 必须在产品卡内无需滚动即可看见
- ✗ 产品选项卡区块绝不要超过 4 个选项卡
- ✗ 绝不要让加入购物车与次要按钮视觉重量相同
- ✗ 绝不要堆过多文案 — 每句话都要挣得位置
- ✗ 页面任何地方都不要居中对齐长正文
- ✗ 产品图绝不要加投影 — 让摄影自己完成工作
- ✗ 移动端绝不要堆叠 reel 卡片 — 保持横向滚动

### 需替换的数据（占位映射）
- `[BRAND_NAME]` — 导航字标、页脚、主视觉 A 标题语境
- `[HERO_A_HEADLINE]` — 2–4 个词，深色背景，80–120px
- `[HERO_A_SUBLINE]` — 8–12 个词，字重 300，弱化
- `[TRUST_STRIP]` — 4 个信任信号：评分、顾客数、运费、保障
- `[PRODUCT_NAME]` — 主视觉 B、产品卡标题
- `[PRODUCT_DESCRIPTOR]` — 1 句，15–17px，中灰
- `[PRICE]` — 在产品卡中突出显示
- `[ACCENT_COLOR]` — 一个 hex，用于 CTA 按钮、激活色板、高亮
- `[SWATCHES]` — 数组：颜色名、hex 值
- `[LIFESTYLE_IMAGES]` — 4 个图片 URL：城市、桌面、旅行、特写
- `[REEL_CARDS]` — 4 项：评价者姓名、星级、引言
- `[GUARANTEE_POINTS]` — 3 项：图标、标题、正文
- `[FOOTER_TAGLINE]` — 页脚品牌列的短品牌句
- `[SOCIAL_LINKS]` — Instagram、Twitter/X、TikTok URL
