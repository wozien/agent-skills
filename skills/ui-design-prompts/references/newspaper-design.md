# Newspaper Design

- **id:** `newspaper-design`
- **别名:** 报纸设计, 大报风格, 新闻排版, 报头版面
- **一句话:** 权威、墨色、编辑分量。
- **适用:**
  - 内容优先与出版类产品
  - Newsletter 与媒体品牌落地页
  - 权威与可信度最重要的产品
  - 研究工具、知识库与情报产品
  - 希望感觉像「权威大报」的完整 SaaS 落地页
- **避免:**
  - 需要明亮、玩味能量的消费应用
  - 面向更年轻、追潮流受众的产品
  - 视觉优先产品（设计工具、照片应用、视频）
  - 速度与行动优先于阅读的产品
- **来源:** https://uidesignprompts.com/prompts/newspaper-design

## Prompt

## 报纸设计系统

### 气质
权威、密集、排印丰富 — 完全建立在大报头版的视觉语言上。多栏网格、栏线、加粗衬线标题，以及宣告「这是一份真正刊物」的报头。每个区块读起来都像报纸的一页: 头版，然后 B 版、C 版、D 版 — 各自有分区线标题。读者感觉自己在看权威信源，而不是营销页。

### 色彩系统
- 背景: 新闻纸米白 `#F7F4EF`
- 墨色: 深黑 `#111111` — 用于文字、边框、栏线和报头条
- 次文字: 深灰 `#444444`
- 弱化/元信息文字: `#888888`
- 栏线灰: 细栏与分区分割用 `#C9C4B8`，更浅内部分割用 `#DDDAD2`
- 红色强调: `#CC0000` — **仅**用于: 突发新闻条、kicker 标签、分区线强调标记、引文署名。每个视口最多 2-3 个可见红色元素。
- 精选/深色元素: `#111111` 背景配 `#F7F4EF` 文字 — 用于精选定价档和主按钮
- 避免: 亮色、渐变、正文内容用深色背景、超出这五色系统的任何颜色

### 字体系统
三套字体，职责严格:

- **展示衬线**（Playfair Display，字重 800-900）: 报头刊名、主标题、评论标题、定价档名。始终紧字距（-0.02em 到 -0.03em）。
- **正文衬线**（Source Serif 4 或 Georgia，字重 400，dek/引文用斜体）: 文章正文、dek、引文、图注。Line-height 1.6-1.65。
- **无衬线**（DM Sans，字重 500-700）: 所有 UI 铬件 — 导航链接、署名、kicker、分区标签、按钮、页脚链接。标签始终大写，letter-spacing 0.06em-0.16em。

**字号阶梯:**
- 报头刊名: clamp(40px, 7vw, 84px)，字重 900，letter-spacing -0.03em
- 主标题（H1）: clamp(26px, 3.4vw, 42px)，字重 900，line-height 1.05
- 评论标题（H2）: clamp(22px, 2.6vw, 32px)，字重 800
- 侧栏故事标题（H3）: 18px，字重 700
- 小故事标题（H4）: 14.5px，字重 700
- 正文: 14.5-15px，line-height 1.65
- Dek/引文: 15-19px，斜体
- 署名/kicker/标签: 10-11px，大写，letter-spacing 0.06-0.16em

**首字下沉:** 主稿第一段使用 `::first-letter` 样式 — font-size 52px，字重 900，float left，line-height 0.82，margin-right 6px。每页只用**一次**，仅主稿。

### 顶栏 + 报头（必需 — 这是身份锚点）
两部分页头结构:

1. **顶部工具条:** `background: #111111`，白/弱化文字，11px 无衬线，左含日期 + 版次标签，右含账户/newsletter/RSS 链接。高度 ~32px。

2. **报头:** 居中，`border-bottom: 4px double #111111`（双线边框，不是单线 — 这是关键签名细节）。包含:
   - 元信息行: 卷/期号（左）· 星形边框标语（中）· 价格/版次信息（右） — 全部 11px 大写无衬线，弱化色
   - 刊名: 巨大衬线展示字，字重 900
   - 标语: 斜体衬线，小，刊名下方 — 引语风格带署名（「Est. 2018」）

### 导航栏
- `border-top` 和 `border-bottom: 1px solid #111111`（细单线夹住导航）
- 分区链接: 11px 大写无衬线，字重 700，letter-spacing 0.08em
- 当前链接: 红字 + 红 2px 底边
- 未激活链接: 黑字，悬停出现边框
- CTA 按钮: 黑底白字，**或**描边变体（透明背景、黑边框） — 皆矩形，无 border-radius

### 突发新闻条
导航正下方通栏细条:
- `background: #CC0000`，白字
- 「Breaking」标签: 白底红字，小大写标签，行内
- 滚动文字: 12px 无衬线，单行（移动端截断或换行）
- 这个元素应有紧迫感，但每页只出现**一次**，紧贴导航下方

### 分区线标题（每个主区块之前都用）
把所有区块绑在一起的重复结构元素:
```
[带红短杠的分区标签] ────────────────────── [X 版 / 期号引用]
```
- 标签: 11px 大写无衬线，字重 700，letter-spacing 0.16em，前接 22×3px 红条（`::before`）
- 水平线: `flex: 1; height: 1px; background: #C9C4B8` 填满剩余空间
- 右侧（可选）: 小弱化 「Section B」/「Section C」标签 — 强化「报纸分页」概念
- 整行下方 `border-bottom: 1px solid #C9C4B8`，`padding: 26px 0 16px`

### 头版 — 四栏网格（核心布局模式）
这是系统中最重要的布局:
```css
.front-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  border-bottom: 3px double #111111;
}
.fcol { padding: 0 20px; border-right: 1px solid #C9C4B8; }
.fcol-lead { grid-column: span 2; } /* 主稿占 4 栏中的 2 栏 */
```
- 第 1-2 栏（合并，「fcol-lead」）: **主稿** — kicker、巨大标题、dek、带图注的特写图、首字下沉正文段、引文、署名
- 第 3 栏: 2-3 条**侧栏故事** — h3 标题、短正文、署名。项之间用 `1px solid` 线分隔
- 第 4 栏: 4-5 条**小简讯**（「In Brief」） — 仅 h4 标题 + 署名，无正文。密度最高的一栏。
- 整个网格包在 `border-bottom: 3px double #111111` 里 — 「双线」标记头版结束

**竖向栏线（`border-right: 1px solid #C9C4B8`）在全部四栏之间强制存在。** 这才让它读起来像报纸，而不是博客网格。

### 数据条（「Newswire」带）
通栏细带，`border-bottom: 3px double #111111`:
- 4 等格，每格 `border-right: 1px solid #C9C4B8`（最后一格没有）
- 数据数字: 衬线，34px，字重 900
- 标签: 10px 大写无衬线，弱化
- 适当处用罗马数字或非常规格式（年数用 「VIII」） — 强化编辑语域

### 功能区（「我们提供什么」 — B 版）
- 前接分区线标题
- 4 列网格（`repeat(4, 1fr)`），每列 `border-right: 1px solid #C9C4B8`
- 每项: 小红衬线编号（「No. 01」）、衬线标题（17px 字重 700）、无衬线正文描述（13px，弱化）
- `border-bottom: 3px double #111111` 收束该区

### 评论 / 社论 + FAQ 区（C 版）
两列分割（2:1 比），中间竖线:
```css
.opinion-grid { grid-template-columns: 2fr 1px 1fr; }
```
- **左（opinion-main）:** 一篇社论 — 斜体 「— The Editorial Board —」标签、大衬线标题、2 段正文，然后作者行（黑底圆形首字母头像 + 姓名 + 角色）放在带边框条内
- **右（opinion-side）:** FAQ 做成问答栏 — 每个问题前红色衬线 「Q.」（15px 加粗衬线），回答缩进 22px，13.5px 弱化文字。细线分隔。
- 这一区把 FAQ 重构成编辑内容 — 应像读「致编辑的信」或问答专栏，而不是 SaaS FAQ 手风琴

### 分类广告 / CTA 区
灵感来自报纸分类广告页:
- 分区线标题标签 「Notices」，右侧 「Classifieds」标签
- 两列网格（2:1）:
  - **主盒:** `border: 2px solid #111111`（比标准栏线更粗），大衬线标题 + 无衬线副文 + CTA 按钮，flex 行布局
  - **侧盒:** `border: 1px solid #111111`，做成 「Help Wanted」分类广告 — 红色大写标签、衬线加粗文字、弱化无衬线副文
- 无圆角、无阴影 — 这些就是纸面上的广告框

### 定价 — 「订阅费率」（D 版）
把定价重构成报纸订阅档:
- 分区线标题: 「Subscription Rates」
- 3 列网格包在单个 `border: 1px solid #111111` 容器内，列之间 `1px solid #C9C4B8`
- 每列: 档位标签（10px 大写弱化）→ 档名（衬线 22px）→ 价格（衬线 38px 字重 900，无衬线 「/mo」后缀降低透明度）→ 斜体描述带底线 → 功能列表（每项前缀红色 em-dash 「—」）→ 全宽按钮
- **精选/中间档:** 反色 — `background: #111111; color: #F7F4EF` — 这是整页**唯一**出现深色背景的地方，成为明确视觉焦点
- 按钮: 矩形，无 border-radius，黑底白字（精选列反色），悬停交换两色

### 页脚
- 4 列网格: 品牌列（1.4fr）+ 3 个链接列（各 1fr）
- 品牌列: 大衬线字标（26px，字重 900）+ 斜体标语/描述
- 链接列标题: 10px 大写无衬线，字重 700，letter-spacing 0.12em，颜色 `#CC0000`
- 链接: 12.5px 无衬线，弱化，悬停下划线 + 加深
- `border-bottom: 1px solid #C9C4B8` 分隔链接网格与底栏
- 底栏: 左版权 + 右法律链接，11px 大写无衬线，弱化

### 图片
- 用对角条纹占位图案（`repeating-linear-gradient(45deg, ...)`）配 `1px solid #111111` 边框 — 表现报纸网版印刷质感
- 每张图下方斜体衬线图注（11.5px，弱化）
- 图片绝不用 border-radius
- 占位绝不用彩色摄影 — 保持去饱和/图案化

### 边框与栏线 — 完整系统
- **双线**（`4px double` 或 `3px double`）: 标记主区块边界（报头底部、头版结束、每个字母分区结束）
- **细单线**（`1px solid #C9C4B8`）: 栏分隔、内部项分隔、分区线标题下划线
- **粗单线**（`2px solid #111111`）: 分类广告主盒边框 — 谨慎用于强调
- **任何地方都没有圆角。** 处处隐含 `border-radius: 0`。
- **任何地方都没有 box-shadow。** 扁平、忠实于印刷。

### 按钮
- 默认: `background: #111111; color: white; border: 1px solid #111111`，矩形，11px 大写无衬线，letter-spacing 0.1em
- 悬停: 反色 — `background: transparent; color: #111111`
- 深色/精选表面上: 反转默认（浅底深字），悬停 → 红
- 绝不圆角、绝不带阴影、绝不带渐变

### 响应式行为
- **头版网格:** 1024px 时 4 列 → 2 列（主稿仍跨两列，侧栏故事和简讯下移，侧线改为顶线）→ 640px 时 1 列（每栏堆叠，侧线换成顶线）
- **功能网格:** 同样 4→2→1 收束模式
- **评论网格:** 1024px 时 2:1 分割 → 单列，竖线隐藏，区块之间插入横线
- **分类广告/定价网格:** 收成单列，并排栏线变成上下栏线
- **数据条:** 移动端 4 列 → 2×2 网格
- 双线与栏线系统必须优雅降级 — 竖变横，绝不完全消失

### 文案语气
- 权威、克制、编辑口吻 — 尽可能第三人称
- 分区标签用真正报纸分区名: 「Front Page」「Markets」「Opinion」「Classifieds」「Section B/C/D」
- 定价档可用传统订阅语言: 「Reader」「Subscriber」「Institutional」
- ✗ 「Check out our awesome new feature drop!」
- ✓ 「A new approach to typographic hierarchy, introduced this quarter.」
