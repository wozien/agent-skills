# Blog Detail Page UI Design

- **id:** `blog-detail-ui`
- **别名:** 博客详情页 UI, 长文导读页, 购买指南文章页, 温暖编辑式阅读
- **一句话:** 清晰建议。温暖细节。为阅读而建。
- **适用:**
  - 长文购买指南与实用技术建议
  - 带对比表和标注日期零售信息的价格指南
  - 带摘要、清单和来源的研究型文章
  - 有既定品牌识别、以内容驱动产品发现的站点
  - 需要在许多章节中清晰导航的教程
- **避免:**
  - 全程需要满幅摄影的以图为主的故事
  - 几乎不需要章节导航的短公告
  - 大转化 CTA 才是主要内容的活动落地页
- **来源:** https://uidesignprompts.com/prompts/blog-detail-ui

## Prompt

## 博客详情 UI — 温暖编辑式设计系统

### 核心方向

为虚构编辑博客构建完整、响应式的文章详情页。让长指南显得可接近、可导航、易于评估。读者应能在主视觉理解主题、在摘要中扫到答案、跳到相关章节、比较表格信息，并看到相关阅读建议。

个性是冷静、实用、温暖、研究导向。结合白色阅读空间、深海军蓝标题、暖纸面板、克制橙色强调和青绿导航。标题用 Space Grotesk，阅读和界面文字用 Inter。视觉签名是柔色调分割主视觉配带框封面，随后是左侧目录索引和宽裕阅读栏。

本规范演示本提示应生成的文章详情 UI。核心页面区块是共享站点导航、文章主视觉、文章正文、有则出现的相关阅读，以及共享页脚。摘要、表格、标注、行内图、清单和资源是内容驱动模块；文章需要时再包含。

### 演示内容与链接行为

- 使用中性、虚构的出版内容。参考预览使用 “Lumen Notes”、作者 “Editorial Team”，以及样本文章 “How to buy a used laptop without the guesswork”。保持主题广泛适用，没有国家特定品牌、地点或市场主张。
- 这是自包含 UI 预览。站点导航、面包屑、分类和作者链接、行内目的地链接、资源、相关文章、页脚、联系和社交链接都是占位。给它们 `href="#"` 和 `data-preview-link`，并阻止默认点击，使它们不导航、不改 URL、不跳到顶部、不打开新标签。这些链接绝不要用真实网站、线上路由、`mailto:` 或 `tel:` 目的地。
- 保持真实的同文档交互可用：跳到文章、目录链接、行内章节引用、搜索、复选框、移动菜单和回到顶部。只有这些功能锚应指向实际区块 ID。
- 任何示例联系详情使用 `hello@example.com`、`+1 (202) 555-0123` 和 “123 Example Street”。这些是展示内容，不是活动联系链接。使用中性资源标题，如 “Battery health reference” 和 “Processor specification reference”。
- 替换文案或链接目的地时，保持下面的布局、组件结构、排印、色板、间距和艺术构图完整。

### 页面架构与区块顺序

```text
共享粘滞站点导航
┌───────────────────────────────────────────────────────────────┐
│ 全宽、柔色调文章主视觉                                        │
│ 首页 > 文章 > 分类 > 当前文章                                  │
│                                                               │
│ 分类链接                       带框封面图                     │
│ 文章标题                       自然图像比例                    │
│ 摘要                           微妙旋转衬底框                  │
│ 日期 · 阅读时长                                                │
│ 作者身份                                                       │
│ ───────────────────────────────────────────────────────────── │
│ 主题药丸  主题药丸  主题药丸                                   │
└───────────────────────────────────────────────────────────────┘
┌───────────────────┬───────────────────────────────────────────┐
│ 本文目录           │ 引言 / 可选更新说明                       │
│                   │ 快速摘要（有用时）                         │
│ 粘滞索引           │ H2 章节与 H3 小节                          │
│ H2 链接            │ 段落、列表、表格、图像                      │
│   H3 链接          │ 建议标注 / 引文                           │
│ 组件标题          │ 清单 / 结论 / 资源                         │
└───────────────────┴───────────────────────────────────────────┘
接下来读 — 最多两行无图阅读行
共享页脚
移动端：固定快捷导航条，带安全区空间
```

- 主视觉、正文、相关区块和共享外壳居中在最大 1280px 容器（`max-w-7xl`）。
- 文章画布：白（`#FFFFFF`）。周围站点和页脚继承浅灰 `#F8F8F8` 背景。
- 主视觉边距：小屏 16px，从 640px 起 24px。正文和相关区块边距：16px。
- 主视觉：低于 1024px 单列；1024px 用 `minmax(0, 1.05fr) minmax(0, 0.95fr)`，列垂直居中。
- 带目录的正文：低于 1024px 单列；1024px 用 `minmax(0, 0.28fr) minmax(0, 0.72fr)`。
- 正文列间距：默认 24px，1024px 时 40px，1280px 时 64px。
- 低于 1024px，散文居中并上限 46rem（736px）。有桌面目录轨时，散文填充分配的右列，而不保留该上限。
- 若没有可导航章节，省略目录 UI，并在每个断点把文章居中在 46rem。
- 网格子项用 `min-width: 0`。宽表在自己的容器内滚动。

### 字体排印系统

- 展示字体：**Space Grotesk**，sans-serif；项目加载字重 500 和 700。标题和突出组件标签使用现有 `font-display` 家族。
- 正文 / 界面字体：**Inter**，system-ui，sans-serif；字重 400、500、600、700。
- 代码：`ui-monospace, SFMono-Regular, Menlo, monospace`。
- 普通阅读文字保持左对齐。说明居中；主视觉文案在每个屏幕尺寸都左对齐。

### 间距、几何与层次

主要在 4px 刻度上工作，使用下面精确的编辑值：

| 关系 | 间距 |
| --- | --- |
| 主视觉外上 / 下 | 移动 24 / 32px；从 768px 起 32 / 40px；从 1024px 起 40 / 48px |
| 面包屑下边距 + 主视觉网格顶内边距 | 16px + 20px；从 1024px 起顶内边距变为 32px |
| 主视觉列 / 堆间距 | 移动 32px；从 768px 起 40px；从 1024px 起 48px |
| 分类到标题 | 16px |
| 标题到摘要 | 20px |
| 摘要到元数据 | 24px |
| 元数据到作者 | 28px |
| 主视觉网格到主题条 | 32px；从 1024px 起 40px |
| 主题条顶内边距 | 分隔后 20px |
| 正文外上 / 下 | 40px；从 768px 起 56px |
| 相邻直接散文块 | 1.15rem（18.4px）基础节奏 |
| H2 / H3 / H4 之前 | 40 / 32 / 28px |
| 主要内容组件 | 上下 32px，受散文包装节奏约束 |
| 相邻行内图 / 散文块 | 24px 上边距规则 |
| 组件页头 / 主体内边距 | 20px；从 640px 起水平/主体内边距变为 24px |
| 摘要瓷砖 / 清单瓷砖内边距 | 16px |
| 相关区块外上 / 下 | 48px；从 768px 起 64px |

散文包装提供基础节奏；各组件提供自己的间距。保留现有组合 CSS 行为，而不是给每个 MDX 元素再加一层空白间距。

几何：
- 主视觉封面外框：16px 圆角；实际图像：12px 圆角；装饰衬底：22px 圆角。
- 摘要、清单、资源、表格和标注外容器：方角。
- 摘要/清单内瓷砖、行内文章图、移动目录和相关行：12px 圆角。
- 主组件图标瓷砖：44px 方形，12px 圆角。标注图标瓷砖：36px 方形，8px 圆角。
- 主题标签和相关箭头按钮：全圆。
- 多数边框：1px。表顶强调：3px 橙。标注左强调：2px。块引用左强调：3px 橙。
- 主视觉框阴影：`0 16px 48px -24px rgba(2,37,57,0.24)`。摘要和清单只用小而微妙的阴影。表格、资源和标注保持扁平。

### 共享站点导航与页脚

在主视觉上使用共享编辑导航。顶部粘滞，z-index 50，近白表面和非常浅的蓝到暖线性渐变。居中容器用 16px 边距，640px 增到 24px，垂直内边距 12px。

- Logo 在左；桌面导航在柔阴影药丸组中；搜索和海军蓝「联系我们」药丸在右。
- 参考桌面标签：主题、评测、编辑精选、文章、关于。出版字标是 “Lumen Notes”，无域名后缀。导航目的地是惰性预览链接。
- 文章导航链接在文章路由上激活。搜索是 44px 圆形控件。
- 低于 1024px，使用现有汉堡菜单和固定底部快捷导航条。条高 72px 加安全区内边距；在页面下预留 `calc(4.75rem + env(safe-area-inset-bottom, 0px))`。
- 共享页脚在站点背景上跟随「接下来读」。桌面：示例联系信息、快速链接、浏览主题和出版描述。小尺寸页脚简化并居中内容；低于 640px 隐藏链接列。
- 页脚区块内边距：移动 24px，从 768px 起 32px，从 1024px 起 64px；底部版权条：垂直 24px。保留社交、滚到顶部和聊天控件作为共享站点组件。社交和聊天目的地是惰性占位；滚到顶部保持功能。

### 文章主视觉 — 背景与面包屑

使用全宽页头，overflow hidden，1px 暖底边，以及此背景：

```css
background-color: #FCFDFE;
background-image:
  radial-gradient(ellipse at 6% 12%, rgba(219,234,254,0.65), transparent 58%),
  radial-gradient(ellipse at 95% 85%, rgba(251,153,28,0.13), transparent 60%);
```

沿右上半加一条非交互 1px 强调，从 40% 不透明度的橙淡入透明。保持背景色调足够微妙以适配深色文字。

面包屑序列：**首页 → 文章 → 分类 → 文章标题**。复用共享面包屑组件，14px 文字，弱化 14px chevron，水平间距 6px，可换行。当前文章是海军蓝、中等字重。截断过长的单个标签，同时保留完整标题 tooltip；把最后一项标为当前页。

### 文章主视觉 — 文案、元数据与作者

左列顺序：
1. 分类链接配 14px 描边 BookOpen 图标，间距 8px，青绿大写 12px semibold 文字，以及文字下偏移 10px 的浅色下划线。
2. 完整文章标题作为唯一 H1。让长标题自然换行。
3. 标题下可选摘要，最大宽 576px。
4. 日期和阅读时长行，配 16px 青绿 CalendarDays 和 Clock 图标。图标到文字间距 8px，元数据组之间 24px，换行时垂直间距 12px。
5. 作者行：48px 白方，12px 圆角和微妙灰边；内含 30px 虚构出版标记或中性用户图标。作者文字在其右 12px。
6. 作者文字：12px 次要「撰稿」眉题，然后 14px semibold 海军蓝姓名，顶间距 2px。示例作者用 “Editorial Team” 配惰性预览链接；其他作者可以是纯文本。

日期行为：仅当格式化后的更新日期与发布日期不同时，才在元数据行显示更新日期。那时把原始发布日期作为作者名下 12px 行显示，顶间距 4px。否则只显示一次发布日期。使用语义 time 元素和可访问的 Published/Last updated 标签。

### 封面图布局与艺术

封面在桌面位于主视觉右列，小屏在作者块下。它是独立编辑图像，所有标题、元数据和作者 UI 都在它外面。

框构造：
- 相对包装，`min-width: 0`；从 1024px 起加 4px 左内边距。
- 装饰衬底矩形超出包装 8px，从 640px 起增到 12px。旋转 1 degree；22px 圆角，80% 不透明度白边，30% 不透明度白底，无指针事件。
- 前景框：白底，90% 不透明度 1px 白边，16px 圆角，6px 内边距，克制海军蓝调阴影。
- 图像：宽 100%，高 auto，12px 圆角。保留其固有宽高比和完整艺术。不要把详情封面强制进固定裁切或 `object-cover` 盒。
- 可用时使用实际本地封面尺寸。回退尺寸是 1200×630，不是所有封面的强制比例。
- 急切加载主视觉图。提供响应式图像尺寸：从 1280px 约 560px，从 1024px 为 45vw，再往下为视口宽减去主视觉边距。
- 回退源：`/images/articles/cover-placeholder.png`。使用有意义的封面 alt 文本。

此编辑风格的新艺术：用暖灰白画布、左上附近小虚构出版标记/字标、大海军蓝主题字母，以及主题相关的笔记本或硬件插画。桃色圆或柔中性形状可支撑插画；青绿和橙色细节把它绑到 UI。重要内容远离图像边缘，并在显示的封面尺寸下可读。封面可以嵌入标题文字；把可访问的页面 H1 作为艺术外的真实 HTML。参考封面使用 “Lumen Notes”，无真实域名或地点。

### 主题条

把主题放在两列主视觉下方，跨主视觉容器。用 1px、10% 不透明度海军蓝分隔线与主视觉分开。换行列表，间距 8px。每个药丸有 70% 不透明度白底、90% 白边、水平 12px 垂直 6px 内边距、全圆端和 12px 次要文字。这些是主题标签，不是分类筛选。文章无标签时省略该条。

### 目录 / 文章索引

从生成标题 ID 的同一编译章节构建导航。按文档顺序包含 H2 和 H3，以及 QuickSummary、Checklist 和 Resources 的可见 H2 标题。H3 链接缩进；标题重复时保持唯一、稳定的 ID。把正文中遗留的 H1 规范成 H2，使主视觉仍是唯一 H1。

**桌面，1024px 及以上：**
- 把索引放在左正文列，`position: sticky; top: 96px; align-self: start`。
- 标题：「本文目录」，14px semibold 海军蓝；暖底部分隔下 12px 内边距，随后 12px 外边距。
- 链接：12px 次要文字，行高 1.45，垂直内边距 4px，右内边距 8px，列表项之间 2px。H3 项左缩进 12px。
- 当前链接：海军蓝，semibold。桌面选择保持纯文字。

**移动和平板，低于 1024px：**

### 文章内容与阅读节奏

把正文渲染为白底 `.article-prose`，无包围卡片。主文案是 16px Inter，阅读墨，行高 1.8。保持段落简洁，允许自然内容流。

- H2：顶边距 40px；H3：32px；H4：28px。
- 有序和无序列表使用真正的小数和实心圆标记，左缩进 21.6px。相邻列表项和嵌套列表间距 8px。
- 强调文字：海军蓝，字重 600。用于短结论、有用数字和关键短语。
- 散文链接：琥珀 `#92400E`，字重 500，1px 下划线，3px 下划线偏移；悬停变海军蓝。
- 水平线：1px 通用边框，垂直边距 40px。
- 作者提供的「最后更新」句可作为普通散文出现在摘要前；它是可选文章内容。
- 把引言散文、建议、结论和行内链接留在阅读栏。对受益于独特视觉结构的信息使用专用模块。

### 交互与无障碍规则

- 使用克制的颜色、边框、下划线和 chevron 过渡。目录滚动条用 150ms 缓动；没有文章入场效果或封面图悬停缩放。
- 尊重目录 chevron 和滚动条过渡的减少动效偏好。
- 使用语义 article、header、heading、time、figure/figcaption、table、定义列表、navigation 和原生复选框元素。
- 给目录导航可访问标签，激活项 `aria-current="location"`，当前面包屑 `aria-current="page"`。
- 在链接和控件上保留可见 2px 青绿焦点描边及适当偏移。表格滚动区使用内嵌青绿环。
- 装饰图标和封面衬底层对辅助技术隐藏。图像保留有意义的 alt 文本。
- 指定处保持移动目录链接和图标导航控件至少 44px 高/宽。
- 在组件页头内重置文章标题边距，使全局散文规则不撑开组件布局。

### 内容模型与占位映射

替换内容时保留组件层级和视觉规则：
- `[ARTICLE_TITLE]`、`[EXCERPT]`、`[CATEGORY]` — 主视觉文案和面包屑；分类：Buying Guide、Price Guide、Brand Guide、Tips、News。
- `[PUBLISHED_DATE]`、`[UPDATED_DATE]`、`[READING_TIME]`、`[AUTHOR]` — 元数据；阅读时长除非显式提供，否则按约 200 词/分钟估算。
- `[COVER_IMAGE]`、`[COVER_ALT]`、`[COVER_DIMENSIONS]` — 完整编辑艺术和真实固有尺寸；文章图放在 `/images/articles/`。
- `[TAGS]` — 主视觉底部的主题药丸。
- `[INTRO]`、`[SECTIONS]`、`[SUBSECTIONS]`、`[CONCLUSION]` — 散文；从实际标题生成索引。
- `[SUMMARY_ITEMS]`、`[SUMMARY_INTRO]`、`[VERDICT]` — 标签/内容对，可选引言和建议。
- `[TABLE_CAPTION]`、`[TABLE_COLUMNS]`、`[TABLE_ROWS]` — 说明性证据和对比；任何示例价格用 USD，无线上零售商数据。
- `[CALLOUT_TITLE]`、`[CALLOUT_VARIANT]`、`[CALLOUT_CONTENT]` — 情境建议，green 或 red。
- `[INLINE_IMAGES]`、`[CAPTIONS]` — 支撑图，各有尺寸和 alt 文本。
- `[CHECKLIST_ITEMS]` — 简洁、可执行的检查步骤。
- `[RESOURCE_ITEMS]` — 每个来源的中性参考标签、惰性预览目的地和可选解释。
- `[RELATED_ARTICLES]` — 文章后最多两行紧凑阅读，配通用标题和惰性预览目的地。
- `[PUBLICATION_NAME]`、`[PUBLICATION_MARK]`、`[CONTACT_DETAILS]` — 虚构博客身份和仅展示的示例联系详情，无真实域名或国家特定文案。

### 设计护栏

- 桌面把目录轨放在左侧，移动端作为折叠面板放在散文上。
- 保留自然封面宽高比，把主视觉文字放在图外。
- 保留白色阅读画布、深散文墨和暖纸组件表面。
- 证据/行动组件保留方角外框和圆角内瓷砖；不要给每个表面都上主视觉框的圆角或阴影。
- 橙色强调保持选择性，链接与周围文字可区分。
- 表格溢出时保留完整阅读字号；滚动表格而不是缩小文章。
- 仅在增加含义处使用内容驱动模块，单一主视觉 H1 和一致标题层级。
- 以紧凑无图阅读列表和共享站点页脚结束。
